// URLs (single Red Hat Satellite book on the Red Hat Portal)
// The single book is built downstream from the Maps guide: every category
// chapter (doc-Satellite_Documentation_Maps/*.adoc) becomes an html/<category>/
// directory and every map below it becomes a page in that directory.
// Each *DocGuideURL therefore points at the guide's landing page in the single
// book, mirroring the xref landing anchors in attributes-map-overrides.adoc;
// guides whose content spans a whole category (Administering, Planning) land on
// the category index page instead. The xref landing anchors are verified
// automatically: the Maps build fails on unresolved xrefs. These portal URLs
// are plain external links the build cannot check, so verify any category or
// page against doc-Satellite_Documentation_Maps manually.
// Each guide defines a whole-guide URL (*DocGuideURL, no trailing #) and derives
// the anchor-prefix URL (*DocURL, trailing #) from it; the whole-guide URL must
// be defined before the derived line (see attributes-base.adoc).

// the guide's landing page. The single book splits most guides across several
// pages, so anchors located elsewhere need per-anchor routing downstream.

// - guides/upstream_filename_to_satellite_link.json
// - lib/foreman_theme_satellite/documentation.rb in RedHatSatellite/foreman_theme_satellite
// - downstream_filename_to_link.json in downstream
