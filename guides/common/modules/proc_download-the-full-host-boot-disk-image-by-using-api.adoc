= Download the full host boot disk image by using {Project} API

[role="_abstract"]
You can download a bootable ISO image for a host to handle provisioning or recovery scenarios.

.Procedure
* Download the full host boot disk image:
+
[options="nowrap", subs="+quotes,attributes"]
----
$ curl \
--output _My_Image_.iso \
--request GET \
--user _My_User_Name_:__My_Password__ \
https://_{foreman-example-com}_/api/bootdisk/hosts/_host_ID_?full=true
----
