= Remove packages from a host

[role="_abstract"]
You can remove packages from a host from the {ProjectWebUI} to uninstall software or resolve dependency conflicts.

.Procedure
. In the {ProjectWebUI}, navigate to *Hosts* > *All Hosts*.
. Select a host.
. On the *Content* tab, click the *Packages* tab.
. Click the options icon for the package you want to remove.
. Select *Remove*.
The {ProjectWebUI} shows a notification for the remote execution job.
