= Configure {SmartProxyServer} with a custom SSL certificate

[role="_abstract"]
If you configure {ProjectServer} to use a custom SSL certificate, configure each of your {SmartProxyServers} with a distinct custom SSL certificate signed by the same Certificate Authority.
