= Mounting the {Project} installation ISO image

[role="_abstract"]
Use this procedure to mount the {Project} installation ISO image in a disconnected environment.

.Procedure

. Create a directory to serve as the mount point for the {Project} installation ISO image:
+
----
# mkdir /media/satellite/
----

. Mount the {Project} installation ISO image to the mount point:
+
----
# mount -o loop _satellite-DVD_.iso /media/satellite
----
