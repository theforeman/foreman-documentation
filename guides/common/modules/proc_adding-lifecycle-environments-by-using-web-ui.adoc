= Adding lifecycle environments to {SmartProxyServers} by using {ProjectWebUI}

[role="_abstract"]
To distribute content through content-enabled {SmartProxyServer}, add lifecycle environments to your {SmartProxyServer}.
{SmartProxyServer} synchronizes the right repositories from {ProjectServer} and provides that content to hosts.

ifndef::orcharhino[]
For more information about creating and managing lifecycle environments, see {ContentManagementDocURL}managing-application-lifecycles[Managing Application Lifecycles] in _{ContentManagementDocTitle}_.
endif::[]

Do not assign the _Library_ lifecycle environment to your {SmartProxyServer} because it triggers an automated {SmartProxy} sync every time the CDN updates a repository.
This might consume multiple system resources on {SmartProxies}, network bandwidth between {Project} and {SmartProxies}, and available disk space on {SmartProxies}.

You can add an environment from the {ProjectWebUI}.

ifdef::containerized[]
Each {SmartProxyServer} is represented by multiple {SmartProxy} records in {Project}.
To add lifecycle environments, you must select the {SmartProxy} record that has the *Pulpcore* feature enabled.
This record is identified by a `-pulp` suffix in its name.

For example, if your {SmartProxyServer} hostname is `{smart-proxy-context}.example.com`, you will see two {SmartProxy} records:

* `{smart-proxy-context}.example.com` - Contains features such as Registration, Templates, and Logs
* `{smart-proxy-context}.example.com-pulp` - Contains the *Pulpcore* feature for content management

You must use the record with the `-pulp` suffix to manage lifecycle environments.
endif::[]

.Procedure
. In the {ProjectWebUI}, navigate to *Infrastructure* > *{SmartProxies}*.
ifdef::containerized[]
. Identify the {SmartProxy} record for your {SmartProxyServer} that has the *Pulpcore* feature.
Look for the record with a `-pulp` suffix in the *Name* column.
endif::[]
ifndef::containerized[]
. Select your {SmartProxyServer} that you want to add a lifecycle to.
endif::[]
. Click *Edit* and navigate to the *Lifecycle Environments* tab.
. From the *All items* list, select the lifecycle environments that you want to add to your {SmartProxyServer}.
The selected environments appear in the *Selected items* list.
. Click *Submit*.
. To synchronize the content to your {SmartProxyServer}, click the *Overview* tab and click *Synchronize*.
. Select either *Optimized Sync* or *Complete Sync*.
ifndef::orcharhino[]
+
For definitions of each synchronization type, see {ContentManagementDocURL}advanced-synchronization-options[Advanced synchronization options].
endif::[]
