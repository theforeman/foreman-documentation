= Import a Red Hat subscription manifest by using {ProjectWebUI}

[role="_abstract"]
You can import a Red{nbsp}Hat subscription manifest into {ProjectServer} by using {ProjectWebUI}.
Import the manifest so that you can enable and synchronize Red{nbsp}Hat repositories in your organization.

.Prerequisites
* You have a Red{nbsp}Hat subscription manifest file.
For more information, see xref:obtain-a-red-hat-subscription-manifest[].

.Procedure
. In the {ProjectWebUI}, ensure that the context is set to the organization you want to use.
. Navigate to *Content* > *Subscriptions*.
. Click the *More actions* icon, and then select *Manage Manifest*.
. In the *Manage Manifest* window, click *Choose File*.
. Navigate to the location that contains the Red{nbsp}Hat subscription manifest file and click *Open*.
