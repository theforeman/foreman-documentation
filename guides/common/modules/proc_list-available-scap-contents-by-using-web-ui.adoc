= List available SCAP contents by using {ProjectWebUI}

[role="_abstract"]
View what SCAP contents are already loaded in {Project} before uploading additional SCAP contents.
You can use {ProjectWebUI} to view available SCAP contents.

.Prerequisites
* Your user account has a role assigned that has the `view_scap_contents` permission.

.Procedure
* In the {ProjectWebUI}, navigate to *Hosts* > *Compliance* > *SCAP contents*.
