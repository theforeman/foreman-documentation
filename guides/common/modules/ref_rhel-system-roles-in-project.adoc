= {RHEL} System Roles in {Project}

[role="_abstract"]
{RHEL} System Roles is a collection of Ansible roles that provide a configuration interface to remotely manage {RHEL} servers.
{Project} includes {RHEL} System Roles as pre-installed Ansible roles that you can import and use for configuration management.

The `rhel-system-roles` package is pre-installed in {SmartProxyServer} container images and includes roles for common system management tasks such as certificate management, firewall configuration, kernel settings, logging, network configuration, SELinux management, storage management, and time synchronization.

Support levels for some of the {RHEL} System Roles might be in Technology Preview.
For up-to-date information about support levels and a complete list of available roles, see https://access.redhat.com/articles/3050101[{RHEL} System Roles].

To use {RHEL} System Roles, import them from your {SmartProxyServer} using the same process as any other Ansible role.
For more information, see xref:import-ansible-roles-and-variables[].
