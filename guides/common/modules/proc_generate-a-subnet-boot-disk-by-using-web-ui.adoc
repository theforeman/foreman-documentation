= Generate a subnet boot disk by using {ProjectWebUI}

[role="_abstract"]
Generate a boot disk ISO not associated with a specific host that chainloads the installer through the Templates {SmartProxy} of a subnet.

.Prerequisites
* Ensure that the `{ipxe-package}` package is installed on your {ProjectServer}.
{Project} builds the boot disk on {ProjectServer}.
* The subnet has a {SmartProxy} with the *Templates* feature assigned.
The *Subnet generic image* action is available only for such subnets.

.Procedure
. In the {ProjectWebUI}, navigate to *Infrastructure* > *Subnets*.
. Click the dropdown menu in the *Actions* column of the required subnet.
. Select *Subnet generic image*.
