= Configuring Puppet smart class parameters

[role="_abstract"]
When Puppet modules need different behavior for different parts of your infrastructure, you can configure smart class parameters in {Project} to override module defaults.
You can set different values based on facts, the organization, location, host group, or individual host level without changing the module code.
