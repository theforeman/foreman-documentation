= Import an Ansible Execution Environment by using {Project} API

[role="_abstract"]
You can import an Ansible Execution Environment in {Project} by using {Project} API.
This helps you reuse existing Ansible Execution Environments or use Ansible Director in a disconnected environment.

.Prerequisites
* Your {Project} account has a role that grants the `create_ansible_execution_environments`, `edit_ansible_execution_environments`, `view_ansible_content`, `view_ansible_execution_environments`, and `view_organizations` permissions.
* If your Ansible Execution Environment is not pullable from a container registry without authentication, upload the container image as Docker type content to {Project}.
Afterwards, get the URL from {Project}:
+
[options="nowrap", subs="verbatim,quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--header "Content-Type: application/json" \
--request GET \
--user "_My_User_Name_:__My_Password__" \
https://{foreman-example-com}/katello/api/docker_tags/ \
| jq ".results[]"
----

.Procedure
. Create a JSON file, for example, `data.json` to define your Ansible Execution Environment:
+
[source, json, options="nowrap", subs="verbatim,quotes,attributes"]
----
{
  "organization_id": "_My_Organization_ID_",
  "execution_environment": {
    "name": "_My_Ansible_Execution_Environment_Name_",
    "container_image_url": "_My_Container_Image_URL_"
  }
}
----
. Import your Ansible Execution Environment:
+
[options="nowrap", subs="verbatim,quotes,attributes"]
----
$ curl \
--data @data.json \
--header "Accept: application/json" \
--header "Content-Type: application/json" \
--request POST \
--user "_My_User_Name_:__My_Password__" \
https://{foreman-example-com}/api/v2/ansible_director/execution_environments/ \
| jq
----

.Verification
* Query the {Project} API to verify that {Project} imported the Ansible Execution Environment successfully:
+
[options="nowrap", subs="verbatim,quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--user "_My_User_Name_:__My_Password__" \
https://{foreman-example-com}/api/v2/ansible_director/execution_environments/ \
| jq ".results | .[]"
----
+
Verify that `import_status` reported by {Project} equals `success`.
