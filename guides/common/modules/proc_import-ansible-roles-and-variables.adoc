= Import Ansible roles and variables

[role="_abstract"]
You can import Ansible roles and variables from the Ansible paths on {ProjectServer} or {SmartProxyServers} that have Ansible enabled.

.Procedure
. Place the roles and variables in the appropriate Ansible paths on all {SmartProxies} from where you want to use the roles.
ifndef::jtbd-administer[]
For more information, see xref:ansible-role-and-collection-paths-in-{project-context}[].
endif::[]
+
If you want to use custom or third party Ansible roles, ensure to configure an external version control system to synchronize roles between {ProjectServer} and {SmartProxyServers}.
. In the {ProjectWebUI}, navigate to *Configure* > *Ansible* > *Roles*.
. Click *Import* to select the {SmartProxy} from which you want to import.
. Select the roles that you want to import.
. Click *Submit*.
