= Configuring Puppet enforcement intervals

[role="_abstract"]
Control when and how often Puppet enforces configuration on your hosts by configuring enforcement intervals.
The OpenVox agent on your hosts runs on a regular schedule to apply Puppet configuration and report back to {Project}.

You can configure enforcement intervals at different levels:

* Globally for all hosts
* For specific host groups
* For individual hosts

{Project} considers hosts to be out of sync if the last Puppet report is older than the combined values of the configured intervals.
This allows you to monitor configuration drift and ensure your hosts remain in the desired state.
