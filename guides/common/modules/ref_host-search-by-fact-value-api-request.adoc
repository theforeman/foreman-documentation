= Host search by fact value API request

[role="_abstract"]
You can filter hosts by specific fact values such as host group, operating system, or custom facts.

This query returns all hosts with the host group `My Host Group`.

Example API request::
+
[options="nowrap", subs="+quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--header "Content-Type: application/json" \
--request GET \
--user _My_User_Name_:__My_Password__ \
https://_{foreman-example-com}_/api/v2/hosts?search=hostgroup=%22My+Host+Group%22 \
| python3 -m json.tool
----

Example API response::
+
[source, json, options="nowrap", subs="+quotes,attributes"]
----
{
    ...
    "results": [
        {
            ...
            "hostgroup_id": 1,
            "hostgroup_name": "My Host Group",
            "name": "_{server-example-com}_",
            ...
        }
    ],
    "search": "hostgroup=\"My Host Group\"",
    ...
}
----
