= Tuning the PostgreSQL database

[role="_abstract"]
Configure PostgreSQL database settings to improve response times.
Tuning PostgreSQL reduces query latency and improves system responsiveness, especially with high database activity.

The PostgreSQL authors recommend disabling Transparent Hugepage on servers running PostgreSQL.
