= Remove lifecycle environments from {ProjectServer} by using {Project} API

[role="_abstract"]
You can remove lifecycle environments that have no successors to clear unused promotion paths.

When deleting lifecycle environments, delete them in reverse order.

.Procedure
* Remove a lifecycle environment:
+
[options="nowrap", subs="+quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--header "Content-Type: application/json" \
--request DELETE \
--user _My_User_Name_:__My_Password__ \
https://_{foreman-example-com}_/katello/api/environments/_My_Lifecycle_Environment_ID_/ \
| python3 -m json.tool
----
+
