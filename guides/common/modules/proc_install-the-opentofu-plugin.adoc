= Install the OpenTofu plugin

[role="_abstract"]
Install the OpenTofu plugin on your {ProjectServer} to provision and manage hosts through OpenTofu.

.Procedure
* On your {ProjectServer}, install the OpenTofu plugin:
+
[options="nowrap", subs="+quotes,verbatim,attributes"]
----
# {foreman-installer} --enable-foreman-plugin-opentofu
----

.Verification
. In the {ProjectWebUI}, navigate to *Administer* > *About*.
. On the *Plugins* tab, verify the installation of the OpenTofu plugin.
. On your {ProjectServer}, verify the installation of OpenTofu:
+
[options="nowrap", subs="+quotes,verbatim,attributes"]
----
# tofu --version
----

.Next steps
* Connect {Project} to an OpenTofu-based compute resource.
For more information, see xref:supported-opentofu-targets[].
