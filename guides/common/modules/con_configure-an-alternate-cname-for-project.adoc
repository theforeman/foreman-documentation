= Configure an alternate CNAME for {Project}

[role="_abstract"]
An alternate CNAME lets you deploy the {Project} web interface on a different domain name than the one that hosts use to connect to {Project}.
Plan this configuration before you install {SmartProxies} or register hosts to avoid redeploying certificates.
