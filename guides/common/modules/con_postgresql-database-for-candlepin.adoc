= PostgreSQL database for Candlepin

[role="_abstract"]
Candlepin stores subscription data in PostgreSQL.
{ProjectServer} needs this database so that hosts can register and access content.

Candlepin is the subscription management service in {Project}.
It records consumers, subscriptions, and manifest data in its own PostgreSQL database, typically named `candlepin`.
{Project} and Pulp use separate databases on the same PostgreSQL instance by default.
Hosts do not require a chef-client connection to consume subscriptions from Candlepin.

This hammer instance is capitalized incorrectly.

When you migrate to an external database, you create dedicated PostgreSQL roles and databases for {Project}, Candlepin, and Pulp.
Installer options such as `--katello-candlepin-db-password` configure how {ProjectServer} connects to the Candlepin database.
