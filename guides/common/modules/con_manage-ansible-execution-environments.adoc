= Manage Ansible Execution Environments

[role="_abstract"]
You can manage Ansible Execution Environments in {Project} to define custom environments to configure hosts.
Ansible Execution Environments are OCI-based container images built by {Project} based on specific base container images and include a specific version of Ansible.

Ansible Execution Environments give you control over the environment used to run Ansible Playbooks and Ansible roles against hosts to configure them.
The base container image defines the Python version.

Ansible Execution Environments are part of organizations.
