= Manage Ansible Execution Environments

[role="_abstract"]
You can manage Ansible Execution Environments in {Project} to define custom environments to configure hosts.
They give you control over the environment used to run Ansible Playbooks and Ansible roles against hosts to configure them.

Ansible Execution Environments are OCI-based container images that provide a specific version of Python and Ansible.
They are part of organizations.

Based on a base container image and version of Ansible, {Project} can build Ansible Execution Environments.
If you already have an Ansible Execution Environment in a container registry or as archive, you can import this to {Project} and use it.
ifdef::orcharhino[]
By default, {Team} provides a supported default Ansible Execution Environment.
endif::[]
