= journald retention and disk space parameters

[role="_abstract"]
You can configure `journald` retention settings to control how much disk space logs consume on the `/var` partition.
Without retention limits, logs can fill the disk on busy {ProjectServer} hosts.

The following table lists recommended `journald` retention values for {ProjectServer}.
For the complete parameter reference, see {RHELDocsBaseURL}9/html-single/configuring_basic_system_settings/index#configuring-a-persistent-journal_assembly_troubleshooting-problems-using-log-files[Configuring a persistent journal in _{RHEL}{nbsp}9 Configuring basic system settings_].

.Recommended journald retention values for {Project}
[cols="2,1,2", options="header"]
|===
| Parameter
| Recommended value
| Reason

| `Storage`
| `persistent`
| Ensures logs survive reboots.

| `SystemMaxUse`
| `10G`
| Caps total journal size on disk.

| `SystemKeepFree`
| `5G`
| Prevents logs from exhausting the `/var` partition.

| `MaxRetentionSec`
| `4week`
| Removes entries older than four weeks regardless of disk usage.

| `MaxFileSec`
| `1week`
| Rotates journal files weekly for easier cleanup.

| `Compress`
| `yes`
| Reduces disk footprint.
|===

[NOTE]
====
When both `SystemMaxUse` and `MaxRetentionSec` are configured, `journald` enforces whichever limit is reached first.
====
