= Stage and promote content across lifecycle environments

[role="_abstract"]
When validating software updates, promote content view versions through sequential lifecycle environments (such as from *Development* through *QA* to *Production*) so that updates are thoroughly tested before reaching production systems.

Lifecycle environments in {Project} separate content into ordered stages from development to production and link content views, hosts, and {SmartProxyServer} synchronization.
You can create environment paths to stage applications and promote content views to deliver new versions to hosts.
