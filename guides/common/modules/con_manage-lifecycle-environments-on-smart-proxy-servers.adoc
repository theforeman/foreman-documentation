= Manage lifecycle environments on {SmartProxyServers}

[role="_abstract"]
A {SmartProxyServer} synchronizes content from {ProjectServer} for the lifecycle environments that you assign to it.
Hosts registered to the {SmartProxyServer} then consume content from the correct environment.

A lifecycle environment path defines an ordered set of lifecycle environments.
When you add a lifecycle environment to a {SmartProxyServer}, the {SmartProxyServer} synchronizes the content view versions that you promote to that environment.
Add the lifecycle environments that hosts require to each {SmartProxyServer}, and remove the environments that you no longer use to stop distributing their content.
