= Tuning the {cache-store} cache

[role="_abstract"]
Understanding {cache-store} tuning helps you improve caching and task tracking performance.
Proper {cache-store} setup keeps memory use stable and improves {Project} responsiveness.

{cache-store} is an in-memory data store.
ifdef::katello,orcharhino,satellite[]
Foreman and Pulp use {cache-store} for caching and Dynflow uses {cache-store} to track its tasks.
endif::[]
ifdef::foreman-el,foreman-deb[]
Foreman uses {cache-store} for caching and Dynflow uses {cache-store} to track its tasks.
endif::[]
Given the way {Project} uses {cache-store}, its memory consumption should be stable.

The {cache-store} authors recommend disabling Transparent Hugepage on servers running {cache-store}.
