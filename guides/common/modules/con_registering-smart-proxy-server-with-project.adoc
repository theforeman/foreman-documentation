= Registering {SmartProxyServer} with {Project}

Review the prerequisites for registering the {SmartProxyServers} to {ProjectServer}.
For more information, see xref::prerequisites-for-registering-{smart-proxy-context}-server-to-{project-context}-server[].

* To register using WebUI, see xref::registering-a-host-to-{project-context}-by-using-web-ui[]
* To register using CLI, see xref::registering-a-host-to-{project-context}-by-using-cli[]
* To register using API, see xref::registering-a-host-to-{project-context}-by-using-api[]
