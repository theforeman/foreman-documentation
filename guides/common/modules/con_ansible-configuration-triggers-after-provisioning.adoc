= Ansible configuration triggers after provisioning

[role="_abstract"]
You can configure hosts through Ansible immediately after the provisioning process through {Project}.

You can control the trigger through parameters.

[cols="30%,10%,10%,50%", options="header"]
|===
| Parameter | Type | Default value | Description
| `ansible_director_configuration_delay` | integer | `600` | Time in seconds between creating a host and starting the remote execution job.
| `ansible_director_configure_after_provisioning` | boolean | `true` | Set to `false` to disable automatic host configuration through Ansible after the provisioning process.
|===
