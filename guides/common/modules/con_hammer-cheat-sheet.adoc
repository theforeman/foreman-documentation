= Hammer cheat sheet

[role="_abstract"]
You can use the examples in the cheat sheet as templates for common Hammer CLI tasks to configure and manage a {ProjectServer} by using either CLI commands or shell script automation.
Run `hammer full-help` on {Project} to view the complete Hammer CLI help.

Some Hammer commands require an organization or a location context.
The following tags mark those commands and show how to set a default context:

_organization-specific_::
Commands with this tag require you to specify an organization.
You can append `--organization _My_Organization_` to the command or set a default organization:
+
[subs="+quotes"]
----
hammer defaults add \
--param-name _organization_id_ \
--param-value _My_organization_ID_
----

_location-specific_::
Commands with this tag require you to specify a location.
You can append `--location _My_Location_` to the command or set a default location:
+
[subs="+quotes"]
----
hammer defaults add \
--param-name _location_id_ \
--param-value _My_location_ID_
----
