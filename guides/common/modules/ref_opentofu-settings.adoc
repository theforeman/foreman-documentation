= OpenTofu settings

[role="_abstract"]
The OpenTofu settings define how {Project} interacts with OpenTofu.

[cols="35%,30%,35%",options="header"]
|====
| Setting | Default value | Description
| *TfState Token Timeout* | `600` | Allowed duration in seconds for OpenTofu to report back to {Project}.
| *SSH-Key Length* | `4096` | Number of bits for SSH keys used to perform image-based host provisioning on OpenTofu.
|====
