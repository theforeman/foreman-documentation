= Point {Project} at the Red Hat CDN by using Hammer CLI

[role="_abstract"]
You can configure {ProjectServer} to download content directly from the global Red{nbsp}Hat CDN or a sovereign CDN endpoint for each organization.
Use this procedure to change the endpoint or to reconnect a disconnected {ProjectServer}.

.Procedure
. Log in to the {ProjectServer} using SSH.
. Use Hammer to reconfigure the CDN:
+
[options="nowrap" subs="+quotes"]
----
$ hammer organization configure-cdn \
--name="_My_Organization_" \
--type=redhat_cdn
----
+
Without `--url`, {Project} retains the organization's existing endpoint if it is a supported Red{nbsp}Hat CDN endpoint.
Otherwise, {Project} uses the configured default endpoint.
+
To select an endpoint explicitly, include the `--url` option:
+
[options="nowrap" subs="+quotes"]
----
$ hammer organization configure-cdn \
--name="_My_Organization_" \
--type=redhat_cdn \
--url https://cdn.redhat.com
----
+
To use a sovereign CDN endpoint, replace the URL with `\https://cdn-eu.redhat.com` for the European Union or `\https://cdn-us.redhat.com` for the United States.
No SSL CA content credential is required for sovereign CDN endpoints.
+
To switch explicitly to the global Red{nbsp}Hat CDN, specify `--url https://cdn.redhat.com`.

.Verification
* Display the organization's CDN configuration:
+
[options="nowrap" subs="+quotes"]
----
$ hammer organization info --name="_My_Organization_"
----
+
Confirm that the CDN configuration's *URL* matches the selected endpoint.
