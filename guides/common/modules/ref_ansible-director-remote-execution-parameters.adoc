= Ansible Director remote execution parameters

[role="_abstract"]
The Ansible Director remote execution parameters help you to customize Ansible Director-based configuration and remote execution (REX) jobs on hosts through {Project}.
This is separate from Script or Ansible-based REX parameters.

You can use Ansible Director-specific parameters to configure Ansible Director-based remote execution separately from Ansible-based REX or script-based REX.
For more information, see xref:ansible-director-parameter-precedence[].

You can use the parameter hierarchy to customize REX for different parts of your environment, for example, through subnets or host groups.
For more information, see xref:host-parameter-hierarchy[].

[cols="35%,30%,35%",options="header"]
|====
| Parameter | Default value | Description
| *ansible_director_ansible_become_method* | `sudo` | Command to switch to users.
One of [`dzdo`, `su`, `sudo`].
If set, this overrides the value of *ansible_become_method*.
| *ansible_director_ansible_become_user* | `root` | User if escalated privileges are required.
If set, this overrides the value of *ansible_become_user*.
| *ansible_director_ansible_ssh_port* | `22` | Port to use for SSH.
If set, this overrides the value of *ansible_ssh_port*.
| *ansible_director_ansible_ssh_private_key_file* | `/usr/share/foreman-proxy/.ssh/id_rsa_foreman_proxy` | Path on {SmartProxy} to SSH private key for SSH.
If set, this overrides the value of *ansible_ssh_private_key_file*.
| *ansible_director_ansible_user* | `foreman-proxy` | User to use for SSH.
If set, this overrides the value of *ansible_user*.
|====
