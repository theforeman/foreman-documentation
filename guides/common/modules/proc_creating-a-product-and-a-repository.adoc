= Creating a product and a repository

[role="_abstract"]
A product in {Project} groups repositories, and a repository in {Project} mirrors an upstream content source.
Create a custom product and add a repository so that {Project} has content to synchronize.

ifdef::satellite[]
[NOTE]
====
If you only want to consume Red{nbsp}Hat content, proceed to xref:importing-a-subscription-manifest-and-enabling-red-hat-repositories[].
====
endif::[]

ifdef::katello[]
This example adds a repository with CentOS content.
endif::[]
ifdef::satellite[]
This example adds a repository with RPM content from EPEL (Extra Packages for Enterprise Linux).
endif::[]

.Prerequisites
* Your {ProjectWebUI} account has administrative privileges.

.Procedure
. In the {ProjectWebUI}, navigate to *Content* > *Products*.
. Click *Create Product*.
To configure the new product:
.. In the *Name* field, enter a name for the product.
ifdef::katello[]
For example: `CentOS Stream`.
endif::[]
ifdef::satellite[]
For example: `EPEL`.
endif::[]
.. Click *Save*.
. On the product page, click *New Repository*.
To configure the new repository:
.. In the *Name* field, enter a name for the repository.
ifdef::katello[]
For example: `BaseOS`.
endif::[]
ifdef::satellite[]
For example: `EPEL 9`.
endif::[]
.. From the *Type* list, select the required repository type.
ifdef::katello[]
For example: `yum`.
endif::[]
ifdef::satellite[]
For example: `yum`.
endif::[]
.. In the *Upstream URL* field, enter the URL of the upstream repository.
ifdef::katello[]
For example: `https://mirror.stream.centos.org/9-stream/BaseOS/x86_64/os/`.
endif::[]
ifdef::satellite[]
For example: `https://dl.fedoraproject.org/pub/epel/9/Everything/x86_64/`.
endif::[]
.. From the *Download Policy* list, select *On Demand* to save disk space.
With this policy, {Project} downloads only the metadata during synchronization and fetches the actual packages when a host requests them.
.. Click *Save*.

.Verification
* In the {ProjectWebUI}, navigate to *Content* > *Products*.
The *Products* page now shows the new product.
The new product contains the new repository.

.Next steps
* Follow xref:synchronizing-your-content[] to synchronize the new repository so that {Project} downloads its metadata and makes it available for distribution.
