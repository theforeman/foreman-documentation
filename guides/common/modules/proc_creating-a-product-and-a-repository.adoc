= Create a product and a repository

[role="_abstract"]
A _product_ groups repositories, and a _repository_ mirrors an upstream content source.
Create a custom product and add an RPM repository so that {Project} has content to synchronize.

ifdef::satellite[]
If you only want to consume Red{nbsp}Hat content, you can skip this step and proceed to xref:importing-a-red-hat-subscription-and-enabling-a-red-hat-repository_{context}[].
endif::[]

.Prerequisites
* You have {ProjectWebUI} access with administrative privileges.

.Procedure
. In the {ProjectWebUI}, navigate to *Content* > *Products*.
. Click *Create Product*.
. In the *Name* field, enter a name for the product, for example `CentOS Stream`.
. Optional: In the *Description* field, enter a description for the product.
. Click *Save*.
. On the product page, click *New Repository* and configure it:
.. In the *Name* field, enter a name for the repository, for example `BaseOS`.
.. From the *Type* list, select *yum*.
.. In the *Upstream URL* field, enter the URL of the upstream repository, for example `https://mirror.stream.centos.org/9-stream/BaseOS/x86_64/os/`.
.. From the *Download Policy* list, select *On Demand* to save disk space.
With this policy, {Project} downloads only the metadata during synchronization and fetches the actual packages when a host requests them.
.. Click *Save*.

You now have a product that contains one repository.
In the next step, you synchronize this repository so that {Project} downloads its metadata and makes it available for distribution.
