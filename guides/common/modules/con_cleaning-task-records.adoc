[id="cleaning-task-records"]
= Cleaning task records

[role="_abstract"]
Task records track background jobs that {Project} executes, such as synchronizing repositories.
ifndef::containerized[]
Configure automatic cleanup or manually clean up outdated tasks to save database space.
endif::[]
ifdef::containerized[]
{Project} cleans up outdated tasks automatically, and you can also clean them up manually to save database space.
endif::[]

ifdef::containerized[]
Automatic task cleanup runs as part of the daily timer.
During the cleaning, {Project} removes the following tasks:

* Tasks that have finished successfully and are older than thirty days
* All tasks that are older than a year

Disabling the automatic task cleanup also disables all the jobs that run with the daily timer.
endif::[]
