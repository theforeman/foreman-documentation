= Managing Puppet configurations to apply to hosts

[role="_abstract"]
When managing host configurations at scale, you need to organize which Puppet modules, classes, and parameters are available to your infrastructure.
This organization helps you deploy consistent configurations across your hosts and keep them updated over time.

After you enable Puppet integration with {Project}, you can install Puppet modules from Puppet Forge or custom sources.
You then import their classes and environments into {Project}, organize classes into reusable configuration groups, and customize module behavior through smart class parameters.
With these configurations organized in {Project}, you can assign appropriate configurations to host groups or individual hosts.
This approach ensures consistency while keeping flexibility for host-specific requirements.
