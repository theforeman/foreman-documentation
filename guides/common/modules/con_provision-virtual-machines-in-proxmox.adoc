= Provision virtual machines in Proxmox

[role="_abstract"]
You can create and manage virtual machines on Proxmox Virtual Environment by using {Project}.
Proxmox integrates the KVM hypervisor and Linux Containers (LXC).

{Project} supports Proxmox 8 and 9.

[NOTE]
====
A Proxmox compute profile cannot set *Start after creation?*.
That option is only on the form of a new host.
A host that you create from a Proxmox compute profile by using Hammer CLI or the API is created powered off unless you add `--compute-attributes start_after_create=1`.
Do not use it for boot-disk-based hosts: the virtual machine would start before the boot disk is attached.
====
