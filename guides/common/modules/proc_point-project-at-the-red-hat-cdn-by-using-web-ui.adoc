= Point {Project} at the Red Hat CDN by using {ProjectWebUI}

[role="_abstract"]
You can configure {ProjectServer} to download content directly from the global Red{nbsp}Hat CDN or a sovereign CDN endpoint for each organization.
Use this procedure to change the endpoint or to reconnect a disconnected {ProjectServer}.

.Procedure
. In the {ProjectWebUI}, navigate to *Content* > *Subscriptions*.
. Click *Manage Manifest*.
. Switch to the *CDN Configuration* tab.
. Select *Red Hat CDN*.
. From the *URL* list, select an endpoint:
* `\https://cdn.redhat.com` for the global Red{nbsp}Hat CDN
* `\https://cdn-eu.redhat.com` for the European Union
* `\https://cdn-us.redhat.com` for the United States
+
If the organization already uses *Red Hat CDN*, the list shows its saved endpoint.
. Click *Update*.
+
{ProjectServer} is now configured to download content from the Red{nbsp}Hat CDN the next time that it synchronizes repositories.
