= Services provided by {ProjectServer}

[role="_abstract"]
{ProjectServer} provides centralized management services for your {Project} deployment.

{ProjectServer} provides the following functionality in {Project}:

ifdef::katello,orcharhino,satellite[]
Content lifecycle management::
{ProjectServer} manages the content lifecycle, including synchronizing, managing, and publishing content to hosts
through content views and lifecycle environments.

Patch management::
{ProjectServer} manages errata and package updates for hosts.

Subscription management::
{ProjectServer} manages subscriptions and entitlements for hosts.
endif::[]

Host configuration::
{ProjectServer} manages configuration of hosts and {SmartProxyServers}.

Host provisioning::
{ProjectServer} manages provisioning of bare-metal and virtual hosts.

Fine-grained authentication::
{ProjectServer} provides role-based access control to grant users access to only the parts of the infrastructure they are responsible for.
