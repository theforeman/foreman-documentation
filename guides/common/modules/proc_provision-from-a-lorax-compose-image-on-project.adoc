= Provision from a {LoraxCompose} image on {Project}

[role="_abstract"]
You can upload a {LoraxCompose} image to {Project} and use this image to provision hosts by using network boot.

ifndef::orcharhino,satellite[]
[NOTE]
====
This feature is available for {EL} hosts only.
====
endif::[]

When you provision from a {LoraxCompose} image, Anaconda installer partitions disks, downloads and mounts the image, and copies files over to a host.

.Prerequisites
* An existing TAR image created by using {LoraxCompose} in {the-Cockpit}.
Ensure that your blueprint to build the image includes the xref:packages-required-in-a-lorax-compose-image[required packages].
* If you want hosts to consume the image from a {SmartProxyServer}, the referenced lifecycle environment, such as Library, must be synchronized to that {SmartProxyServer}.
For more information, see {InstallingSmartProxyDocURL}add-lifecycle-environments-to-{smart-proxy-context}-servers-by-using-web-ui[Add lifecycle environments to {SmartProxyServers} by using {ProjectWebUI}].

.Procedure
. On {Project}, create a {customproduct}, add a {customfiletype} repository to this product, and upload the image to the repository.
ifndef::orcharhino[]
For more information, see {ContentManagementDocURL}import-an-iso-image-by-using-web-ui[Import an ISO image by using {ProjectWebUI}].
endif::[]
. Create and publish a content view that contains your {customfiletype}.
. In the {ProjectWebUI}, navigate to *Configure* > *Host Groups*.
. Select the host group that you want to use.
. Click the *Parameters* tab, and then click *Add Parameter*.
. Create a parameter named `kickstart_liveimg` with type *string* and set the value to the full URL of the image location or the file name of the image inside a published content view.
The URL depends on whether hosts retrieve the image from {ProjectServer} or from a {SmartProxyServer}:
* Full URL on {ProjectServer}: `\https://_{foreman-example-com}_/pulp/content/_My_Organization_Label_/_My_Lifecycle_Environment_/custom/_My_Product_Label_/_My_Repository_Label_/_My_Image_Name_.tar`
* Full URL on a {SmartProxyServer}: `\https://_{smartproxy-example-com}_/pulp/content/_My_Organization_Label_/_My_Lifecycle_Environment_/custom/_My_Product_Label_/_My_Repository_Label_/_My_Image_Name_.tar`
* Image file name: `_My_Image_Name_.tar`
+
You can use the image file name only if the `kt_activation_keys` parameter is defined for the host.
+
[WARNING]
====
If a host is assigned to multiple content view environments, {Project} uses the first assigned content view environment to locate the image.
If you change the order of the content view environments assigned to the host, rebuilding the host might use a different environment from the one that you intended.
To ensure {Project} uses the correct image, ensure that the desired boot image exists in the first content view environment assigned to the host.
For more information, see {ContentManagementDocURL}content-view-environment-ordering-and-priority[Content view environment ordering and priority].
====
+
If a content source is assigned to the host, {Project} uses the content source {SmartProxy} of the host.
If a content source is not assigned, {Project} uses {ProjectServer}.
. Click *Submit* to save your changes.
