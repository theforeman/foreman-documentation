= Configuration management with Puppet in {Project}

[role="_abstract"]
To automate host configurations across your infrastructure and keep them consistent, {Project} integrates with OpenVox server for Puppet-based configuration management.
This automation helps you consistently manage configurations of hosts registered to {Project}.

Puppet is a configuration management tool to automate host configurations across your infrastructure.
{Project} uses OpenVox server as the Puppet-compatible central server for the integration.
