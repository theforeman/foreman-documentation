= Monitor hosts by using {Insights} in cloud

[role="_abstract"]
You can use the {Insights} advisor service in the {RHCloud} to assess system health on hosts running {RHEL}.
You can use the {Insights} dashboard in the {RHCloud} to quickly analyze recommendations for remediation, vulnerabilities, and more.
