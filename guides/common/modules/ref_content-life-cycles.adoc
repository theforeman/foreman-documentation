[id="content-life-cycles"]
= Content life cycles

[role="_abstract"]
You can manage content views in lifecycle environments in {ProjectName} by using Hammer CLI commands.

[cols="3a,7a",options="header",subs="+quotes"]
|====
|Subcommand |Description and tasks
|`*lifecycle-environment*` 
xref:general-hammer-information[_organization-specific_]
|Create a lifecycle environment:
[subs="+quotes"]
----
$ hammer lifecycle-environment create \
--description "_My_Description_" \
--name "_My_Lifecycle_Environment_" \
--prior "_My_Prior_Lifecycle_Environment_"
----
List lifecycle environments:
[subs="+quotes"]
----
$ hammer lifecycle-environment list
----
|`*content-view*` 
xref:general-hammer-information[_organization-specific_]
|Create a content view:
[subs="+quotes"]
----
$ hammer content-view create \
--description "_My_Description_" \
--name "_My_Content_View_" \
--repository-ids _My_Repository_ID_1_,_My_Repository_ID_2_
----
Add repositories to a content view:
[subs="+quotes"]
----
$ hammer content-view add-repository \
--name "_My_Content_View_" \
--repository-id _My_Repository_ID_
----
Add Puppet modules to a content view:
[subs="+quotes"]
----
$ hammer content-view puppet-module add \
--content-view "_My_Content_View_" \
--name "_My_Puppet_Module_"
----
Publishing a content view:
[subs="+quotes"]
----
$ hammer content-view publish \
--id _My_Content_View_ID_
----
Promoting a content view:
[subs="+quotes"]
----
$ hammer content-view version promote \
--content-view "_My_Content_View_" \
--to-lifecycle-environment "_My_Lifecycle_Environment_"
----
Incremental update of a content view:
[subs="+quotes"]
----
$ hammer content-view version incremental-update \
--content-view-version-id _My_Content_View_Version_ID_ \
--lifecycle-environment-ids _My_Lifecycle_Envirionment_ID_1_,_My_Lifecycle_Envirionment_ID_2 \
--packages _My_Package_ID_1_,_My_Package_ID_2_
----
|====
