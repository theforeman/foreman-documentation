= Installing {SmartProxyServer}

[role="_abstract"]
ifndef::satellite[]
To install {SmartProxyServer}, register it to {ProjectServer}, configure repositories, install packages, and set up SSL certificates for content management and remote execution.
endif::[]
ifdef::satellite[]
To install {SmartProxyServer}, register it to {ProjectServer}, configure repositories, install packages, configure it to pull container images from {ProjectServer}, and set up SSL certificates for content management and remote execution.
endif::[]
