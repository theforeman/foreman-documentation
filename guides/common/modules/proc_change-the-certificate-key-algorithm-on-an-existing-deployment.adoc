= Change the certificate key algorithm on an existing deployment

[role="_abstract"]
You can change the key algorithm of the certificates that {ProjectName} generated earlier.
Because the algorithm change also changes the CA key, you must renew the CA.
Renewing the CA reissues the CA certificate and every certificate that it signed, so you do not need a separate certificate renewal.

[WARNING]
====
Renewing the CA invalidates all previously issued certificates.
After you change the algorithm, you must refresh the CA certificate on all registered hosts.
This does not apply to custom certificates.
====

.Procedure
. Change the key algorithm and renew the CA.
+
--
* If you did not previously set an algorithm explicitly, add the new algorithm:
+
[options="nowrap", subs="+quotes,attributes"]
----
# {foremanctl} deploy --add-certificate-algorithm ECC --certificate-ca-renew
----
* If an algorithm already persists, remove the algorithm when you add the new one:
+
[options="nowrap", subs="+quotes,attributes"]
----
# {foremanctl} deploy --remove-certificate-algorithm RSA --add-certificate-algorithm ECC --certificate-ca-renew
----
--
