= Organize {Project} resources for management

[role="_abstract"]
Organize {Project} resources into a logical structure so that you can manage hosts and related objects effectively across your infrastructure.

Hosts belong to an organization and a location.
You can associate existing virtual machines with {Project}, assign hosts to organizations and locations, and change content view environments to control which software versions hosts can consume.
