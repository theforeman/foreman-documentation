= Troubleshooting {Insights} in {RHCloud}

[role="_abstract"]
You can troubleshoot issues with {Insights} in the {RHCloud} by checking logs and certificates.

To troubleshoot hosts monitoring, you can try the following approaches:

ifndef::containerized[]
* You can find the logs in the `/var/log/foreman/production.log` file.
endif::[]
ifdef::containerized[]
* View the logs for all {insights-iop} services:
+
[options="nowrap" subs="+quotes,attributes"]
----
# journalctl --unit "iop*"
----
+
The names of all {insights-iop} services have the `iop` prefix.
+
For the full list of commands to view and filter service logs, such as following log output in real time or tracing a request by its correlation ID, see {AdministeringDocURL}viewing-service-logs[Viewing service logs]{InAdministeringDoc}.

* View the logs for a specific service unit:
+
[options="nowrap" subs="+quotes,attributes"]
----
# journalctl --unit _iop-service-unit_
----
endif::[]

* If you have problems connecting to {Insights}, ensure that your certificates are current.
Refresh your subscription manifest to update your certificates.
