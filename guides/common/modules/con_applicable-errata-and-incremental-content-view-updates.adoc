= Applicable errata and incremental content view updates

[role="_abstract"]
An erratum is applicable to a host when it contains updates for packages installed on the host.
An erratum is installable when it is available in the content view environments associated with the host.
If an erratum is applicable but not installable, create an incremental content view version to publish the update and make it available to the host.
