= Sovereign CDN endpoints

[role="_abstract"]
Red{nbsp}Hat provides geographically aware Content Delivery Network (CDN) endpoints for users in the European Union and the United States.
You can use these sovereign CDN endpoints to synchronize RPM content from endpoints in your preferred jurisdiction.

The following sovereign CDN endpoints are available:

* `cdn-eu.redhat.com` for the European Union
* `cdn-us.redhat.com` for the United States

These endpoints are drop-in replacements for the default `cdn.redhat.com` endpoint and you can switch between them freely.
To configure a sovereign CDN endpoint, use the custom CDN configuration option and enter the URL of the sovereign endpoint.
Sovereign CDN endpoints do not require an SSL CA content credential.
