= System requirements for {Project}

[role="_abstract"]
Before installing {Project}, verify that the deployment host runs a supported operating system, is dedicated to {ProductName}, and provides the minimum CPU and memory resources.

You can deploy {Project} on the following operating systems:

include::snip_supported-project-operating-systems.adoc[]

ifdef::foreman-el,katello,orcharhino[]
* Installing {Project} on a system with Extra Packages for Enterprise Linux (EPEL) is not supported.
endif::[]
* Install {ProductName} on a freshly provisioned system that serves no other function except to run {ProductName}.
* Ensure the system has at least {project-minimum-cpus} and {project-minimum-memory} of memory.
