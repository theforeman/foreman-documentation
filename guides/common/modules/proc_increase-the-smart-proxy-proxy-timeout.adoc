= Increase the {SmartProxy} proxy timeout

[role="_abstract"]
During periods of very high concurrency, you might experience timeouts in the {SmartProxyServer} to {ProjectServer} communication.
You can alleviate this by increasing the default proxy timeout.

.Procedure
* Increase the default timeout by adding the following tunable in `/etc/foreman-installer/custom-hiera.yaml`:
+
[options="nowrap", subs="+quotes,verbatim,attributes"]
----
apache::mod::proxy::proxy_timeout: 600
----
