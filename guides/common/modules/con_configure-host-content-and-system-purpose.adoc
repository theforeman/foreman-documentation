= Configure host content and system purpose

[role="_abstract"]
Configure host content delivery settings and system purpose attributes to ensure hosts receive the right software and subscription reporting reflects actual usage.

{Project} provides content configuration capabilities that control which software hosts can install and how subscription usage is reported:

* *System purpose* defines the intended role, usage, and service level agreement for RHEL hosts to improve subscription reporting accuracy in Red Hat Hybrid Cloud Console
* *Module streams* allow you to manage application versions independently from the base operating system on Enterprise Linux 8 hosts
* *Custom repositories* extend available content beyond default Red Hat repositories
* *Content sources* determine which {SmartProxyServer} provides content to each host for load balancing and performance optimization

Use these configuration capabilities together to ensure correct software delivery and accurate subscription tracking.
Start by setting system purpose for subscription compliance reporting, enable the repositories and module streams hosts need, then optimize content delivery by selecting appropriate content sources.

Common configuration workflows include:

Initial host registration:: Set system purpose during or immediately after host registration using web UI for interactive setup, CLI for automation, or bulk operations for efficiency across multiple hosts.

Application lifecycle management:: Change module streams on Enterprise Linux 8 hosts to switch application versions, such as moving from PostgreSQL 10 to PostgreSQL 13, without upgrading the base operating system.

Custom content delivery:: Enable custom repositories containing organization-specific packages, scripts, or configuration files that hosts need beyond standard Red Hat content.

Performance optimization:: Change content sources to point hosts to closer or less-loaded {SmartProxyServer}s, improving content download speeds and balancing infrastructure load.

Subscription compliance:: Update system purpose attributes when host roles change to ensure subscription reporting in Red Hat Hybrid Cloud Console accurately reflects how systems are used.
