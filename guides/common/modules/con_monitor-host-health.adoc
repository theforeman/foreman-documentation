= Monitor host health

[role="_abstract"]
Monitor host status so that you can identify hosts that need attention and prioritize remediation across your fleet.

In {ProjectWebUI}, you can browse and filter your host inventory, review {client-os} lifecycle status when it is available, and check global and sub-status indicators for configuration, compliance, errata, and related host conditions.
