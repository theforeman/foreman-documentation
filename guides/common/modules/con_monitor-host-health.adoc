= Monitor host health

[role="_abstract"]
Monitor host status to identify hosts that need attention and prioritize remediation across your fleet.

In {ProjectWebUI}, you can browse and filter your host inventory, check each host's global status, and inspect sub-statuses for areas such as configuration, compliance, and errata.
For {RHEL} hosts, you can also review lifecycle status, a specific sub-status that shows upcoming end-of-support events.
