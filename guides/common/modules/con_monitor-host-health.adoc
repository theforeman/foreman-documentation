= Monitor host health

[role="_abstract"]
Monitor host inventory, lifecycle status, and health indicators to quickly identify systems that need attention and prioritize remediation efforts across your fleet.

{Project} provides comprehensive host monitoring through three levels of visibility:

* *Inventory visibility* allows you to browse, search, and customize views of all hosts in one central location
* *Lifecycle tracking* monitors RHEL end-of-support dates to help you plan updates before systems lose support
* *Health monitoring* uses global and sub-status indicators to show at-a-glance health with detailed diagnostic information

Use these monitoring capabilities together for effective fleet management.
Start by reviewing your inventory to understand scope, check lifecycle status to identify hosts approaching end-of-support, then monitor health indicators to prioritize remediation work.

Common monitoring workflows include:

Daily operations:: Review the Hosts Overview page to identify hosts with Warning or Error global status, then investigate sub-status details to determine the specific issue requiring attention.

Lifecycle planning:: Check lifecycle status to identify RHEL hosts approaching end-of-support, then plan upgrade schedules to maintain support coverage across your infrastructure.

Compliance monitoring:: Track which hosts are non-compliant with OpenSCAP policies using the Compliance sub-status, prioritizing remediation based on policy severity.

Post-update verification:: After applying system updates, check the Traces sub-status to identify hosts requiring process restarts or reboots to complete the update.

Proactive maintenance:: Identify hosts requiring security updates using the Errata sub-status, prioritizing those with needed security errata to reduce vulnerability exposure.
