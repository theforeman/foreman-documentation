= {Project} MCP server overview

[role="_abstract"]
{Project} provides a Model Context Protocol (MCP) server so that you can query and manage your {Project} inventory from MCP-compatible AI applications by using natural language.

You deploy the MCP server from a container image that {Team} provides and connect it to the AI application that runs your MCP client.
The MCP server accesses {Project} with your credentials, so your MCP client cannot obtain data that you do not have permission to access.

By default, the MCP server is read-only.
You can query your inventory and generate reports from it, for example, a report of all subnets and the hosts that are assigned to them.

When you start the MCP server, you can also grant it permissions to change your {Project}.
For example, you can start remote execution jobs on your hosts, and publish and promote content views.
