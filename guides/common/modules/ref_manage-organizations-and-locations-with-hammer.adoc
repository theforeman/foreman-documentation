= Manage organizations and locations with Hammer

[role="_abstract"]
You can manage organizations, locations, and repositories in {ProjectName} by using Hammer CLI commands.

[cols="3a,7a",options="header",]
|====
|Subcommand |Description and tasks
|`*organization*` |Create an organization:
[subs="+quotes"]
----
$ hammer organization create \
--name "_My_Organization_"
----
List organizations:
[subs="+quotes"]
----
$ hammer organization list
----

|`*location*` |See the options for organization

|`*subscription*` 
xref:general-hammer-information[_organization-specific_]
|Upload a subscription manifest:
[subs="+quotes"]
----
$ hammer subscription upload \
--file ~/_My_Red_Hat_Manifest_
----

|`*repository-set*` 
xref:general-hammer-information[_organization-specific_]
|Enable a repository:
[subs="+quotes"]
----
$ hammer repository-set enable \
--basearch "_My_Architecture_" \
--name "_My_Repository_" \
--product "_My_Product_" \
--releasever "_My_Release_Version_"
----

|`*repository*` 
xref:general-hammer-information[_organization-specific_]
|Synchronize a repository:
[subs="+quotes"]
----
$ hammer repository synchronize \
--name "_My_Repository_" \
--product "_My_Product_"
----
Create a {customrepo}:
[subs="+quotes"]
----
$ hammer repository create \
--content-type "_My_Content_Type_" \
--name "_My_Repository_" \
--product "_My_Product_" \
--publish-via-http true \
--url "_My_URL_"
----
Upload content to a {customrepo}:
[subs="+quotes"]
----
$ hammer repository upload-content \
--id _My_Repository_ID_ \
--path ~/_My_Content_ \
--product "_My_Product_"
----
|====
