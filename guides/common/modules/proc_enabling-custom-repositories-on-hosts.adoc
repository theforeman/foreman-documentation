= Enabling {customrepos} on hosts

[role="_abstract"]
You can enable {customrepos} on a host from the {ProjectWebUI}.
This allows the host to install packages or consume other content from repositories you have added to {Project}.

.Prerequisites
* The repositories you require are available in the content view environments of the host.

.Procedure
. In the {ProjectWebUI}, navigate to *Hosts* > *All Hosts* and select a host.
. Select the *Content* tab, then select *Repository sets*.
ifdef::satellite[]
. From the dropdown, you can filter the *Repository type* column to *Custom*.
endif::[]
. Select the desired number of repositories or click the *Select All* checkbox to select all repositories.
. Open the options menu, and select *Override to Enabled*.
