= Planning {Project} update

[role="_abstract"]
Updating {Project} applies a patch release to your {ProjectServer} and {SmartProxyServers}.
Regular updates help keep your {Project} environment up-to-date and typically present minimal disruption to your operations.

Updating a {ProjectServer} or {SmartProxyServer} performs a patch release.
A patch release updates your {ProjectServer} and {SmartProxyServer} to a new patch release version, such as from {ProjectVersion}.0 to {ProjectVersion}.1.

[IMPORTANT]
====
Perform updates regularly to resolve security vulnerabilities and other issues.
Updating a {ProjectServer} or {SmartProxyServer} is often fast and non-disruptive to your operating environment.
====

ifdef::containerized[]
Always update {ProjectServer}, {SmartProxyServer}, or the operating system by using `{foremanctl}`.
endif::[]
ifndef::containerized[]
Always update {ProjectServer}, {SmartProxyServer}, or the operating system by using `{foreman-maintain} update`.
endif::[]
If there are pending {ProjectServer} updates, updating the operating system will update both.
