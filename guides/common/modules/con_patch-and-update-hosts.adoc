= Patch and update hosts

// The wording in this introduction is temporary; make sure to review it before publishing based on what exacty content the top-level job ends up including.
[role="_abstract"]
Apply important security fixes to affected hosts so that your hosts remain secure.

Before you apply updates, configure the content path for each host: set system purpose for subscription reporting in {RHCloud}, enable the required repositories or module streams, and select the content source that delivers packages to the host.
