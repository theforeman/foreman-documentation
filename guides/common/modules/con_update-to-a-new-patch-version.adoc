= Update to a new patch version

[role="_abstract"]
Update {ProjectServer} and {SmartProxyServers} to the next patch version to receive bug fixes, security updates, and minor improvements.

A patch release updates your {ProjectServer} and {SmartProxyServer} to a new patch release version, such as from {ProjectVersion}.0 to {ProjectVersion}.1.
Regular updates help keep your {Project} environment up-to-date and typically present minimal disruption to your operations.

[IMPORTANT]
====
Perform updates regularly to resolve security vulnerabilities and other issues.
Updating a {ProjectServer} or {SmartProxyServer} is often fast and non-disruptive to your operating environment.
====
