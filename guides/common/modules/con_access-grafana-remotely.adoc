= Access Grafana remotely

[role="_abstract"]
Grafana runs on `+http://localhost:3000+` on {ProjectServer} and is only accessible locally.
You can use SSH tunneling to access Grafana from a remote workstation.

Choose the procedure that matches your workstation's operating system and tools.
