= Ansible and Ansible Director integration with {Project}

[role="_abstract"]
You can use the Ansible plugin and the Ansible Director plugin on {Project} at the same time.
The plugins are unrelated.

If you want to configure your hosts with Ansible roles that are stored on {SmartProxies} and you only need a single version to configure all hosts, pick the Ansible plugin.
It is easier to set up and has less maintenance overhead compared to Ansible Director.

If you rely on specific versions of Ansible or Python to configure your hosts, or if you want to stage your Ansible content in different lifecycle environments similar to software, pick the Ansible Director plugin.
It provides more flexibility to configure hosts and helps test changes in a staging environment before rolling them out to hosts in production.

{Team} recommends picking a single configuration management plugin to configure hosts.
