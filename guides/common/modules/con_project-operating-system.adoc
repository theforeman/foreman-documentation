= {Project} operating system

[role="_abstract"]
You can install {Project} on the following supported operating systems.

ifdef::foreman-deb[]
You can run {ProjectServer} and {SmartProxyServers} on Debian 12, Debian 13, Ubuntu 22.04, and Ubuntu 24.04.
endif::[]
ifndef::foreman-deb[]
ifndef::containerized[]
You can run {ProjectServer} and {SmartProxyServers} on {EL} 9.
endif::[]
ifdef::containerized[]
You can run {ProjectServer} and {SmartProxyServers} on {EL} 9 or {EL} 10.
endif::[]
endif::[]
Katello plugin packages, which provide content management capabilities, are only available for {EL}.

{Team} only packages {Project} for x86_64.
