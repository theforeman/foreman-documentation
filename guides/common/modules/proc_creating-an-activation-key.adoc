= Creating an activation key

[role="_abstract"]
An activation key assigns a lifecycle environment, content view, and other settings to hosts during registration.
Every time you reuse the key to register a host, {Project} applies the same settings to the host.

In this example, you create an activation key that points to the *Development* environment and the *My Content View* content view.

.Procedure
. In the {ProjectWebUI}, navigate to *Content* > *Lifecycle* > *Activation Keys*.
. Create an activation key:
.. Click *Create Activation Key*.
.. In the *Name* field, enter a name.
For example: `My Development Key`.
.. Ensure the *Unlimited hosts* checkbox is selected.
.. On the *Content view environments* card, click *Assign content view environments*.
.. Select the *Development* lifecycle environment.
.. Select the content view you created, for example *My Content View*.
.. Click *Save* to save the content view environment.
. Click *Save* to create the activation key.
+
You now have an activation key that you can use to register hosts.
Each registered host will automatically receive content from the *Development* lifecycle environment and the *My Content View* content view.
