= Troubleshooting {insights-iop}

[role="_abstract"]
You can check the logs to troubleshoot issues with {insights-iop}.

ifndef::containerized[]
To troubleshoot hosts monitoring, you can find the logs in the `/var/log/foreman/production.log` file.
endif::[]

ifdef::containerized[]
The names of all {insights-iop} services begin with the `iop` prefix.
To view the logs for all {insights-iop} services, enter the following command:

[options="nowrap" subs="+quotes,attributes"]
----
# journalctl -u "iop*"
----

For the full list of commands to view and filter service logs, such as following log output in real time or tracing a request by its correlation ID, see {AdministeringDocURL}viewing-service-logs[Viewing service logs] in _{AdministeringDocTitle}_.

If you have recently updated hosts or synced repositories and expect new CVEs to appear on the Vulnerability page, manually trigger a Vulnerability Management as a Service (VMaaS) scan to incorporate the new content:

[options="nowrap" subs="+quotes,attributes"]
----
# systemctl start iop-service-vuln-vmaas-sync.service
----
endif::[]
