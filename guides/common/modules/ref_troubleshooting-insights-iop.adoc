= Troubleshooting {insights-iop}

[role="_abstract"]
You can check the logs to troubleshoot issues with {insights-iop}.

ifndef::containerized[]
To troubleshoot hosts monitoring, you can find the logs in the `/var/log/foreman/production.log` file.
endif::[]
ifdef::containerized[]
To troubleshoot hosts monitoring, list the available {insights-iop} service units:

[options="nowrap" subs="+quotes,attributes"]
----
# systemctl list-units --all --type=service "iop*"
----

View the logs for the relevant service unit:

[options="nowrap" subs="+quotes,attributes"]
----
# journalctl --unit _iop-service-unit_
----

For more information about viewing and filtering service logs, such as following log output in real time or tracing a request by its correlation ID, see {AdministeringDocURL}viewing-service-logs[Viewing service logs] in _{AdministeringDocTitle}_.
endif::[]
