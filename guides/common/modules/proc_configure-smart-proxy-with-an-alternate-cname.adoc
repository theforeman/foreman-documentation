= Configure {SmartProxy} with an alternate CNAME

[role="_abstract"]
You can configure an alternate CNAME for {SmartProxy} with the default certificate.

.Procedure
. On {ProjectServer}, add the alternate CNAME to the Subject Alternative Name (SAN) of the {SmartProxy} certificate by regenerating the authentication bundle for {SmartProxyServer}:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} auth-bundle _{smartproxy-example-com}_ \
--certificate-renew \
--proxy-alias _My-Alternate-FQDN.example.com_
----
+
You can specify the `--proxy-alias` option more than once.
To generate the bundle for a {SmartProxyServer} for the first time, omit the `--certificate-renew` option.
. Copy the authentication bundle to {SmartProxyServer}.
. On {SmartProxyServer}, add the alternate CNAME to the list of hostnames that {SmartProxy} accepts:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} deploy-proxy \
--auth-bundle /root/_{smartproxy-example-com}_.tar.gz \
--server-alias _My-Alternate-FQDN.example.com_
----
+
You can specify the `--server-alias` option more than once.
{SmartProxy} stores the values of the `--server-alias` option.
To declare additional names later, run the `{foremanctl} deploy-proxy` command with the new names only.
