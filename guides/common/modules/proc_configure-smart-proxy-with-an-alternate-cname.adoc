= Configure {SmartProxy} with an alternate CNAME

[role="_abstract"]
You can configure an alternate CNAME for {SmartProxy} with the default certificate.

.Procedure
. Add an alternate CNAME to a new installation or an existing deployment of {SmartProxy}:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} deploy-proxy --server-alias _My-Alternate-FQDN.example.com_
----
+
You can specify the option more than once.
To declare additional names later, run the `{foremanctl} deploy` command again with all the names that you want {SmartProxy} to accept.
