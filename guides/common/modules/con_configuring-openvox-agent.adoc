= Configuring OpenVox agent

[role="_abstract"]
To enable Puppet integration, you must install and configure the OpenVox agent on your managed hosts.
The OpenVox agent communicates with {ProjectServer} or {SmartProxyServer} to enforce configuration management.

You can configure the OpenVox agent on a host in one of the following ways:

* During host provisioning by including the `puppet_setup` snippet in your provisioning template
* During host registration using the registration templates
* Manually on an existing host

Choose the method that best fits your deployment workflow.
