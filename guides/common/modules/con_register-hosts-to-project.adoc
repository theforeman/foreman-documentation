= Register hosts to {Project}

[role="_abstract"]
Register hosts that were not provisioned through {Project} to manage them with {ProjectServer} or {SmartProxyServer}.

You can register hosts by using global registration.
Generate a registration command in {Project} and run it on each host to install the required client packages and enroll the host.
