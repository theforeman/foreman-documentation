= Set up content sources

[role="_abstract"]
By default, {Project} downloads Red{nbsp}Hat content from the Red{nbsp}Hat Content Delivery Network (CDN) at `cdn.redhat.com`.
You can change the content source to a custom CDN, such as an internal mirror, or to a sovereign CDN endpoint that keeps content synchronization within your preferred jurisdiction.
