= Configure OpenVox agent on a host during provisioning

[role="_abstract"]
If you prefer to install and configure the OpenVox agent on a host when provisioning the host through {Project}, add the `puppet_setup` snippet to your provisioning template.
A configured OpenVox agent is required on the host for Puppet integration with your {Project}.

.Prerequisites
ifdef::satellite[]
* {project-client-name} OpenVox repository is synchronized on {ProjectServer} and enabled in the activation key you use.
+
include::snip_openvox-client-repos.adoc[]
* You have an activation key.
For more information, see {ContentManagementDocURL}manage-activation-keys[Manage activation keys].
endif::[]
ifdef::katello[]
* You created a product and repository for the upstream OpenVox agent.
For more information, see {ContentManagementDocURL}adding-content-to-{project-context}[Adding content to {Project}].
* You created an activation key that enables the OpenVox agent repository for hosts.
For more information, see {ContentManagementDocURL}manage-activation-keys[Manage activation keys].
endif::[]
ifdef::orcharhino[]
* You created a product and repository containing the OpenVox agent and synchronized the repository to {Project}.
For more information, see {ContentManagementDocURL}adding-content-to-{project-context}[Adding content to {Project}].
* You created an activation key that enables the OpenVox agent repository for hosts.
For more information, see {ContentManagementDocURL}manage-activation-keys[Manage activation keys].
endif::[]

.Procedure
. In the {ProjectWebUI}, navigate to *Hosts* > *Templates* > *Provisioning Templates*.
. Select a provisioning template depending on your host provisioning method.
For more information, see {ProvisioningDocURL}kinds-of-provisioning-templates[Kinds of provisioning templates].
ifdef::foreman-el,foreman-deb[]
. For shell-based provisioning templates, ensure the `voxpupuli_repo` snippet runs before `puppet_setup` as follows:
+
[options="nowrap", subs="+quotes,verbatim,attributes"]
----
<%= snippet 'voxpupuli_repo' %>
----
+
The `Kickstart default` and `Preseed default finish` templates already include this snippet when Puppet setup and an OpenVox repository are enabled.
The `AutoYaST SLES default` template configures the repository in its AutoYaST settings instead.
The `Agama sles default` template does not configure this repository.
For Agama on SLES using the official repository, create a snippet named `Agama sles default custom finish pre` with the following content.
Mark it as a snippet; the default template includes it before `puppet_setup`:
+
[options="nowrap", subs="+quotes,verbatim,attributes"]
----
<%= snippet 'voxpupuli_repo' %>
----
endif::[]
. Ensure the `puppet_setup` snippet is included as follows:
+
[options="nowrap", subs="+quotes,verbatim,attributes"]
----
<%= snippet 'puppet_setup' %>
----
+
ifdef::foreman-el,foreman-deb,katello[]
Note that this snippet is already included in the templates shipped with {Project}, for example, in `Agama sles default`, `AutoYaST SLES default`, `Kickstart default`, and `Preseed default finish` templates.
endif::[]
ifdef::orcharhino,satellite[]
Note that this snippet is already included in the templates shipped with {Project}, for example, in the `{client-provisioning-template-default}` template.
endif::[]
ifdef::katello,orcharhino,satellite[]
. Enable the OpenVox agent using a host parameter in global parameters, a host group, or for a single host.
Add a host parameter named `enable-puppet8`, select the *boolean* type, and set the value to `true`.
endif::[]
ifndef::katello,orcharhino,satellite[]
. Enable the official OpenVox repository using one of the following host parameters in global parameters, a host group, or for a single host:

* Add `enable-openvox8-repo` for OpenVox 8.
* Add `enable-openvox9-repo` for OpenVox 9.

+
Select the *boolean* type and set the value to `true`.
Enable only one OpenVox version.
Do not set `enable-puppetlabs-repo`, `enable-official-puppet8-repo`, or `enable-puppet8` to `true` at the same time.
+
The official SUSE repository is for SLES, not openSUSE.
For openSUSE, provide a compatible OpenVox repository separately and set either `enable-openvox8` or `enable-openvox9` to `true` instead of an `-repo` parameter.
endif::[]
. Set configuration for the OpenVox agent.
* If you use an integrated OpenVox server, ensure that you select a Puppet {SmartProxy}, Puppet CA {SmartProxy}, and Puppet environment when you create a host.
* If you use a non-integrated OpenVox server, either set the following host parameters in global parameters, or a host group, or when you create a host:
** Add a host parameter named `puppet_server`, select the *string* type, and set the value to the hostname of your OpenVox server, such as `openvox.example.com`.
ifdef::foreman-el,foreman-deb[]
** If you use `Agama sles default`, add the `force-puppet` host parameter, select the *boolean* type, and set it to `true`.
endif::[]
** Optional: Add a host parameter named `puppet_ca_server`, select the *string* type, and set the value to the hostname of your Puppet CA server, such as `puppet-ca.example.com`.
If `puppet_ca_server` is not set, the OpenVox agent will use the same server as `puppet_server`.
** Optional: Add a host parameter named `puppet_environment`, select the *string* type, and set the value to the Puppet environment you want the host to use.
ifdef::katello,orcharhino,satellite[]
. Ensure your host has access to the OpenVox agent packages from {ProjectServer} by using an appropriate activation key.
endif::[]
