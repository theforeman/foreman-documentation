= Define an image for hosts on {opentofu-target} by using {ProjectWebUI}

[role="_abstract"]
Define an image that you use to provision hosts on {opentofu-target} through {Project}.

.Procedure
. In the {ProjectWebUI}, navigate to *Infrastructure* > *Compute Resources*.
. Select your {opentofu-target} compute resource.
. Click *Create Image*.
. In the *Name* field, enter the name of your image.
. From the *Operating System* list, select the operating system of the image on {opentofu-target}.
. From the *Architecture* list, select the architecture of the image on {opentofu-target}.
. In the *Username* field, enter the user name of your image.
. Select *User Data* if the image supports user data.
. In the *Password* field, enter the password of the user on your image.
ifdef::stackit-cloud[]
. In the *Image ID* field, enter the UUID of the image on {opentofu-target}.
endif::[]
ifndef::stackit-cloud[]
. From the *Image* list, select the image on {opentofu-target}.
endif::[]
. Click *Submit* to save the values to {Project}.

.Next steps
* Create a compute profile that uses this image.
For more information, see xref:create-a-predefined-configuration-for-hosts-on-{opentofu-target-id}-by-using-web-ui[].
