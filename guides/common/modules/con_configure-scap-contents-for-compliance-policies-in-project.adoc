= Configure SCAP contents for compliance policies in {Project}

[role="_abstract"]
You can upload SCAP data streams and tailoring files to define compliance policies.
These policies define the requirements for scanning systems against security standards such as Defense Information Security Agency Security Technical Implementation Guide (DISA STIG) or Payment Card Industry Data Security Standard (PCI DSS).
