= Troubleshooting hosted {Insights} connectivity

[role="_abstract"]
You can identify certificate and manifest problems that prevent {Project} from connecting to {Insights} in the {RHCloud} and refresh the subscription manifest to restore connectivity.

.Procedure
. On your {ProjectServer}, open the `/var/log/foreman/production.log` file and search for certificate or manifest errors.
+
For example, you might see a message similar to the following:
+
[options="nowrap",subs="+quotes,attributes"]
----
A manifest is not available for org: _My_Organization_, or it has expired, or been deleted. skipping insights sync
----
+
For commands to view and filter service logs, see {AdministeringDocURL}viewing-service-logs[Viewing service logs].
. Refresh your subscription manifest to update the certificates that {Project} uses to authenticate with {Insights}:
.. In the {ProjectWebUI}, ensure the context is set to the organization you want to use.
.. Navigate to *Content* > *Subscriptions*.
.. On the *Subscriptions* page, click *Manage Manifest*.
.. In the *Manage Manifest* window, click *Refresh*.
