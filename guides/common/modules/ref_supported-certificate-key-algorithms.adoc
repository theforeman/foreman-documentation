[id="supported-certificate-key-algorithms"]
= Supported certificate key algorithms

[role="_abstract"]
You configure the key algorithm for generated certificates by using the following options of the `{foremanctl} deploy` command.
Each option corresponds to an Ansible variable of the `certificates` role.

[options="header"]
|====
| Option | Ansible variable | Description
| `--add-certificate-algorithm` | `certificates_algorithms` | Key algorithm to generate: `RSA` (default), `ECC`, or `ML-DSA-87`.
| `--remove-certificate-algorithm` | `certificates_algorithms` | Removes an algorithm from the persisted list.
| `--certificate-algorithm-rsa-size` | `certificates_algorithm_rsa_size` | Key size for RSA keys only (the default is 4096).
| `--certificate-algorithm-ecc-curve` | `certificates_algorithm_ecc_curve` | Elliptic curve for ECC keys only (the default is `secp384r1`).
|====

[NOTE]
====
Only one algorithm can be active at a time.
Specifying more than one algorithm causes the deployment to fail.
The algorithm list exists for forward compatibility with planned dual-certificate support.
====
endif::[]
