= Logging architecture overview

[role="_abstract"]
{ProjectServer} routes all service output through `systemd` and `journald`.
You can use `journalctl` commands to view, filter, and manage logs for all {Project} services from a single interface.

All {Project} services log to standard output (`stdout`) by default.
The container runtime captures this output and forwards it to `journald`.
