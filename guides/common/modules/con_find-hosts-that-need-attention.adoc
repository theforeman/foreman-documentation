= Find hosts that need attention

[role="_abstract"]
You can use the {ProjectWebUI} to browse your managed hosts and identify which hosts require attention.
The host list displays global status indicators and sub-statuses that help you quickly find hosts with errors or warnings.
You can customize the table columns to focus on the health metrics most relevant to your environment.
