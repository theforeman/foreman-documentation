= Install {SmartProxyServer} from {ProjectServer}

[role="_abstract"]
ifndef::satellite[]
To install {SmartProxyServer}, register it to {ProjectServer}, configure repositories, install packages, and set up SSL certificates for content management and remote execution.
endif::[]
ifdef::satellite[]
To install {SmartProxyServer} in a connected environment, register it to {ProjectServer}, configure repositories, install packages, configure it to pull container images from {ProjectServer}, and set up SSL certificates for content management and remote execution.

If your {SmartProxyServer} cannot access {ProjectServer} and the Red{nbsp}Hat Content Delivery Network (CDN) over the network, install it from an ISO image instead.

endif::[]
