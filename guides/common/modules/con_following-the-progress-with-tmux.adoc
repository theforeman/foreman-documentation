= Following the progress with tmux

[role="_abstract"]
ifdef::upgrading-connected[]
Using a utility such as `tmux` helps follow the progress of the upgrade without the need to maintain a continuous shell session.
endif::[]
ifdef::updating[]
Using a utility such as `tmux` helps follow the progress of the update without the need to maintain a continuous shell session.
endif::[]

ifdef::upgrading-connected[]
Because of the lengthy upgrade time, use a utility such as `tmux` to suspend and reattach a communication session.
You can then check the upgrade progress without staying connected to the command shell continuously.
endif::[]
ifdef::updating[]
You can use a utility such as `tmux` to suspend and reattach a communication session.
You can then check the update progress without staying connected to the command shell continuously.
endif::[]

ifdef::upgrading-connected[]
If you lose connection to the command shell where the upgrade is running, you can see the logs in `{installer-log-file}` to check if the process completed successfully.
endif::[]
ifdef::updating[]
If you lose connection to the command shell where the update is running, you can see the logs in `{installer-log-file}` to check if the process completed successfully.
endif::[]

For more information about using `tmux`, see the `tmux(1)` man page on your system.
