= Exclude hosts from {Insights} analytics

[role="_abstract"]
You can exclude hosts from {Insights} analytics by setting host parameters that control client installation and inventory uploads to the {RHCloud}.

`host_registration_insights`::
Setting this parameter to `false` prevents {ProjectServer} from forwarding data from the {Insights} client on hosts to {Insights} services.
The {Insights} client is not installed on newly registered hosts.

`host_registration_insights_inventory`::
Setting this parameter to `false` excludes the host from the {Project} host inventory that is uploaded to the {RHCloud} for hosted {Insights}.
+
If you exclude a host that is already reported on the https://console.redhat.com/[{RHCloud}], {Project} still removes the host from the inventory automatically.
This process can take some time to complete.

You can set these parameters at any level.
