= Exclude hosts from {Insights} analytics

[role="_abstract"]
You can exclude hosts from {Insights} analytics by setting host parameters that control client installation and inventory uploads to the {RHCloud}.

* The `host_registration_insights` parameter controls installation of the {Insights} client and forwarding of client data.
If the parameter is set to `false`, {ProjectServer} does not forward data from the {Insights} client on the host to {Insights} services, and the {Insights} client is not installed on newly registered hosts.
* The `host_registration_insights_inventory` parameter controls inventory uploads for hosted {Insights}.
If the parameter is set to `false`, {Project} excludes the host from the host inventory that is uploaded to the {RHCloud}.
+
If you exclude a host that is already reported on the https://console.redhat.com/[{RHCloud}], {Project} still removes the host from the inventory automatically.
This process can take some time to complete.

You can set these parameters at any level.
