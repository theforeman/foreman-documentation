= {SmartProxy} configuration tuning

[role="_abstract"]
{SmartProxy} tuning distributes load and delivers content across networks.
Properly configured {SmartProxies} reduce {ProjectServer} load and improve remote execution performance.

{SmartProxies} do not improve performance for operations that extensively use the {Project} API,
ifdef::katello,orcharhino,satellite[]
such as host registration or package profile update.
endif::[]
ifdef::foreman-el,foreman-deb[]
such as host registration.
endif::[]
