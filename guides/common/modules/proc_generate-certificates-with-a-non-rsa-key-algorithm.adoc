= Generate certificates with a non-RSA key algorithm

[role="_abstract"]
When you deploy {ProjectServer} for the first time, you can generate the self-signed certificate set with a non-RSA key algorithm.
If you have already deployed {ProjectServer}, see xref:change-the-certificate-key-algorithm-on-an-existing-deployment[] instead.

.Procedure
. Deploy {ProjectServer} with the required key algorithm.
+
--
* To generate an ECC certificate set on the default curve:
+
[options="nowrap", subs="+quotes,attributes"]
----
# {foremanctl} deploy{foremanctl_initial_deploy_opts} --add-certificate-algorithm=ECC
----
* To generate an ECC certificate set on a specific curve:
+
[options="nowrap", subs="+quotes,attributes"]
----
# {foremanctl} deploy{foremanctl_initial_deploy_opts} --add-certificate-algorithm=ECC --certificate-algorithm-ecc-curve=_secp521r1_
----
* To generate an ML-DSA certificate set:
+
[options="nowrap", subs="+quotes,attributes"]
----
# {foremanctl} deploy{foremanctl_initial_deploy_opts} --add-certificate-algorithm=ML-DSA-87
----
--
