= Synchronize content between {ProjectServer}s over a network

[role="_abstract"]
When operating in a multi-server deployment where the servers can communicate over a network, you can distribute content from an upstream {ProjectServer} to downstream {ProjectServer}s by using network synchronization over HTTPS.
