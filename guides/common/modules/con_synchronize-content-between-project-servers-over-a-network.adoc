= Synchronize content between {ProjectServer}s over a network

[role="_abstract"]
Distribute content from an upstream {ProjectServer} to downstream {ProjectServer}s to support multi-server deployments across different locations, networks, or organizational boundaries.

You can synchronize the Library environment, content view versions, or individual repositories between {ProjectServer}s using {ISS}.

Choose the synchronization method based on your network connectivity:

* If your downstream {ProjectServer} can communicate with the upstream {ProjectServer} over a network, configure network synchronization over HTTPS.
* If your downstream {ProjectServer} is air gapped with no network connection to the upstream {ProjectServer}, use the export and import method to transfer content physically.
