= Updating {SmartProxyServer}

[role="_abstract"]
You can update your {SmartProxyServer} to the latest packages published by {Team}.

ifdef::satellite,orcharhino[]
.Prerequisites
* The {SmartProxy} product on your {ProjectServer} has been synchronized.
ifdef::containerized[]
* The `{SmartProxy} Container Images` product on your {ProjectServer} has been synchronized.
endif::[]
* A new version of the content view with which the {SmartProxy} is registered has been published and promoted.
endif::[]

.Procedure
ifdef::containerized[]
. Optional: Use the health check option to determine if the system is ready for update:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} health
----
+
Review the results and address any highlighted error conditions before performing the update.
. Stop {Project} services:
+
[options="nowrap" subs="+quotes,attributes"]
----
# systemctl stop foreman.target
----
. Upgrade the packages on your {SmartProxyServer}:
+
[options="nowrap" subs="+quotes,attributes"]
----
# dnf upgrade
----
. Pull the updated container images:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} pull-images
----
. Redeploy the {SmartProxy} to perform the upgrade:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} deploy-proxy
----
endif::[]
ifndef::containerized[]
. On your {SmartProxyServer}, upgrade all packages:
+
[options="nowrap" subs="+quotes,verbatim,attributes"]
----
# {project-package-update}
----
. Reconfigure {SmartProxyServer}:
+
[options="nowrap" subs="+quotes,verbatim,attributes"]
----
# {foreman-installer}
----
endif::[]

ifdef::containerized[]
.Verification
* Verify that all {Project} services are running:
+
[options="nowrap" subs="+quotes,verbatim,attributes"]
----
# {foremanctl} health
----
endif::[]
