= Increasing the logging level for OpenVox server

You can find the logs in `/var/log/puppetlabs/puppetserver/`.

.Prerequisites
* You have enabled Puppet on your {Project}.
For more information, see {ManagingConfigurationsPuppetDocURL}[_{ManagingConfigurationsPuppetDocTitle}_].

.Procedure
* Set the logging level to `debug`:
+
[options="nowrap", subs="+quotes,verbatim,attributes"]
----
# {foreman-installer} --puppet-server-additional-settings log_level:debug
----
