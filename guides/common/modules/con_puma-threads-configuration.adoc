= Puma threads configuration

[role="_abstract"]
Thread count determines how many parallel operations each worker process can handle.
The relationship between threads and workers impacts resource utilization and parallel request handling without increasing memory consumption.

For example, we have compared these two setups:

[width="100%",cols="50%,50%",options="header",]
|===
|{Project} VM with 8 CPUs, 40 GiB RAM |{Project} VM with 8 CPUs, 40 GiB RAM
|`--foreman-foreman-service-puma-threads-max 16` |`--foreman-foreman-service-puma-threads-max 8`
|`--foreman-foreman-service-puma-workers 2` |`--foreman-foreman-service-puma-workers 4`
|===

Using more workers with the same total threads gives about 11% speedup for highly concurrent registrations.
More workers do not use more CPU or RAM but provide better performance.
