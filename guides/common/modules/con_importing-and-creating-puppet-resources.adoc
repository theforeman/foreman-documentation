= Importing and creating Puppet resources

[role="_abstract"]
After installing Puppet modules on {ProjectServer} or {SmartProxyServer}, you must import the Puppet classes and environments into {Project}.
You can also create custom Puppet environments and configuration groups to organize your Puppet configuration.

Puppet classes define the configuration to apply to hosts.
Puppet environments allow you to maintain different versions of Puppet modules for different sets of hosts.
Configuration groups are collections of Puppet classes that you can assign to hosts as a single unit.
