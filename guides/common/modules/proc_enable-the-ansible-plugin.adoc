[id="enable-the-ansible-plugin"]
= Enable the Ansible plugin

[role="_abstract"]
ifndef::satellite[]
Enable the Ansible plugin on {ProjectServer} and {SmartProxyServers}.
endif::[]
ifdef::satellite[]
Enable the Ansible plugin on {SmartProxyServers} to run Ansible roles on hosts.
endif::[]

.Procedure
ifndef::satellite[]
. Enable the Ansible plugin on your {ProjectServer}:
+
[options="nowrap" subs="+quotes,attributes"]
----
ifndef::containerized[]
# {foreman-installer} \
--enable-foreman-plugin-ansible \
--enable-foreman-proxy-plugin-ansible
endif::[]
ifdef::containerized[]
# {foremanctl} deploy \
--add-feature ansible
endif::[]
----
. On all {SmartProxyServers} that you want to use to run Ansible roles on hosts, enable the Ansible plugin:
endif::[]
ifdef::satellite[]
* On all {SmartProxyServers} that you want to use to run Ansible roles on hosts, enable the Ansible plugin:
endif::[]
+
[options="nowrap" subs="+quotes,attributes"]
----
ifndef::containerized[]
# {foreman-installer} --enable-foreman-proxy-plugin-ansible
endif::[]
ifdef::containerized[]
# {foremanctl} deploy-proxy --add-feature ansible
endif::[]
----
