= Configure {Project} with an alternate CNAME

[role="_abstract"]
You can configure an alternate CNAME for {Project} with the default {Project} certificate.
ifndef::containerized[]
Note that the procedures for users of a default {Project} certificate and custom certificate differ.
endif::[]

ifdef::containerized[]
.Prerequisites
* You know every alternate hostname that clients, load balancers, monitoring systems, and automation use to reach {Project}.
endif::[]

.Procedure
ifdef::containerized[]
. Add an alternate CNAME to a new installation or an existing deployment of {Project}:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} deploy --server-alias _My-Alternate-FQDN.example.com_
----
+
The `--server-alias` option sets the Subject Alternative Names of the {Project} certificate and the hostnames that {Project} and the {SmartProxy} on {ProjectServer} accept in HTTP host headers.
{Project} responds with a `403 Forbidden` error to a request that uses a hostname you did not declare.
+
You can specify the option more than once.
To declare additional names later, run the `{foremanctl} deploy` command again with all the names that you want {Project} to accept.
+
The option applies only to {ProjectServer}.
Declare the names of an external {SmartProxyServer} by running the `{foremanctl} deploy-proxy --server-alias` command on that {SmartProxyServer}.
endif::[]
ifndef::containerized[]
. If you have installed {Project} with a default {Project} certificate and want to configure {Project} with an alternate CNAME, generate a new default {Project} SSL certificate with an additional CNAME on {ProjectServer}:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foreman-installer} --certs-cname _My-Alternate-FQDN.example.com_ --certs-update-server
----
. If you have not installed {Project}, you can add the `--certs-cname _My-Alternate-FQDN.example.com_` option to the `{foreman-installer}` command to install {Project} with an alternate CNAME.
endif::[]
. If you use {Project} with a custom certificate, when creating a custom certificate, include the alternate CNAME records to the custom certificate.
For more information, see {InstallingServerDocURL}create-a-custom-ssl-certificate-for-{project-context}_{project-context}[Create a Custom SSL Certificate for {ProjectServer}].
ifdef::containerized[]
+
A custom certificate that covers the alternate CNAME is not sufficient on its own.
You must also declare the name with the `{foremanctl} deploy --server-alias` command so that {Project} accepts it in HTTP host headers.
