= Synchronize content between {Project} Servers in air-gapped environments

[role="_abstract"]
When operating in an environment with limited network connectivity, you can transfer content from an upstream {ProjectServer} connected to the internet to a downstream {ProjectServer} that is completely isolated from all external networks.
