= Importing a Red Hat subscription manifest by using {ProjectWebUI}

[role="_abstract"]
You can import a Red{nbsp}Hat subscription manifest into {ProjectServer} by using {ProjectWebUI}.
Import the manifest so that you can enable and synchronize Red{nbsp}Hat repositories in your organization.

.Prerequisites
* You have a Red{nbsp}Hat subscription manifest file.
For more information, see xref:obtaining-a-red-hat-subscription-manifest[].

.Procedure
. In the {ProjectWebUI}, ensure the context is set to the organization you want to use.
. Navigate to *Content* > *Subscriptions*.
. If no manifest is imported, click *Import a Manifest*.
To import a manifest when one is already present, open the actions menu and click *Manage manifest*.
. In the *Manage Manifest* window, on the *Manifest* tab, next to *Import new manifest*, click *Upload*.
You can also drag the manifest `.zip` file onto *Drag here* or *Upload a zip file*.
. Select the Red{nbsp}Hat subscription manifest `.zip` file.

The import starts when you select the `.zip` file.
