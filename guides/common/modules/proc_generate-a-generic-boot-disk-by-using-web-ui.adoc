= Generate a generic boot disk by using {ProjectWebUI}

[role="_abstract"]
Generate a boot disk ISO not associated with a specific host that chainloads the installer from {ProjectServer}.

This image is also available from the `/disks/generic` URL path on your {ProjectServer} for users logged in to the {ProjectWebUI}, for example, `\https://{foreman-example-com}/disks/generic`.
By using the API, download the image from the `/api/bootdisk/generic` path.

.Prerequisites
* Ensure that the `{ipxe-package}` package is installed on your {ProjectServer}.

.Procedure
. In the {ProjectWebUI}, navigate to *Infrastructure* > *Subnets*.
. Click *Boot disk* above the list of subnets.
. Select *Generic image*.
