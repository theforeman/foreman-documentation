= Monitor hosts by using {Insights} in {Project}

[role="_abstract"]
You can use local services of {insights-iop} to assess system health on hosts running {RHEL} without connecting to the {RHCloud}.
{insights-iop} provides advisor recommendations and vulnerability reports.
