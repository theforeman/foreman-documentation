= Create a {customproduct} by using Hammer CLI

[role="_abstract"]
Create a {customproduct} to group repositories you add manually before you define {customrepos} or upload packages.

.Procedure
* Create a product:
+
[options="nowrap" subs="+quotes"]
----
$ hammer product create \
--name "_My_Name_" \
--organization-id _My_Organization_ID_
----
