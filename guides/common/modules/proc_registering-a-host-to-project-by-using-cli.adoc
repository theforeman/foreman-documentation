= Registering a host to {Project} by using Hammer CLI

[role="_abstract"]
You can register a host to {Project} by using Hammer CLI with registration templates.
This also enables you to set up various integration features and host tools during the registration process.

.Prerequisites
include::snip_registering-a-host-prerequisites.adoc[]

.Procedure
. Generate the host registration command:
+
[options="nowrap" subs="+quotes,attributes"]
----
ifdef::foreman-el,foreman-deb[]
$ hammer host-registration generate-command
endif::[]
ifdef::katello,satellite,orcharhino[]
$ hammer host-registration generate-command \
--activation-keys "_My_Activation_Key_"
endif::[]
----
+
If your hosts do not trust the SSL certificate of {ProjectServer}, append `--insecure true` to disable SSL validation.
+
For more information, see the Hammer CLI help with `hammer host-registration generate-command --help`.
. Connect to your host using SSH and run the registration command as `root`.
