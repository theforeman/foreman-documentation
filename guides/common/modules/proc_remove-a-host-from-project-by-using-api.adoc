= Remove a host from {Project} by using {Project} API

[role="_abstract"]
You can remove a host from {Project} by using {Project} API when you decommission the host or no longer need to manage it.
The host is permanently deleted from the {Project} database.

.Procedure
* Delete your host from {Project}:
+
[options="nowrap", subs="+quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--header "Content-Type: application/json" \
--request DELETE \
--user _My_User_Name_:__My_Password__ \
https://_{foreman-example-com}_/api/v2/hosts/_{server-example-com}_ \
| python3 -m json.tool
----
