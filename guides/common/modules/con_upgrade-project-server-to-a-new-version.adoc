= Upgrade {ProjectServer} to a new version

[role="_abstract"]
Upgrade {ProjectServer} and {SmartProxyServers} from {ProjectName} {ProjectVersionPrevious} to {ProjectName} {ProjectVersion} to get new features, bug fixes, and security fixes.
A major version upgrade runs health checks and validations before it changes your environment, and it requires planned downtime.
