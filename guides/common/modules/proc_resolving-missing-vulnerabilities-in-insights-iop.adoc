= Resolving missing vulnerabilities in {insights-iop}

[role="_abstract"]
You can update vulnerability metadata when expected CVEs are missing from the *Vulnerability* page in {insights-iop} so that host evaluations include the latest advisories.

If you expect new CVEs but do not see them on the *Vulnerability* page, update the vulnerability metadata by synchronizing content.
You can trigger a scan by synchronizing a repository.
When you update a host, {Project} pulls any missing CVEs during vulnerability evaluation.

.Procedure
. Start the vulnerability metadata download service:
+
[options="nowrap",subs="+quotes,attributes"]
----
# systemctl start iop-vuln-metadata-download.service
----

[NOTE]
====
The download service relies on a single-threaded scan.
If synchronization is already in progress, the service might fail or time out.
====
