= Ansible Director parameter precedence

[role="_abstract"]
The Ansible Director parameter precedence determines applied customization options for Ansible Director-based configuration and remote execution (REX) jobs on hosts through {Project}.

Script and Ansible-based remote execution parameters::
Parameters for the Ansible and Remote Execution plugins define the baseline for all REX jobs in {Project}.
Their values are overridden by values of any other level.

Ansible Director-specific parameters::
Parameters for the Ansible Director plugin take precedence over base REX parameters.
Their names have an `ansible_director_` prefix so you can set up different custom options for the Ansible/Remote Execution plugins and Ansible Director plugin.

Remote execution job inputs::
REX job inputs take the highest precedence and override any other values or settings.
This only applies to parameters that are exposed to the {ProjectWebUI} or {Project} API.
