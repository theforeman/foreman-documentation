= Update a disconnected {SmartProxyServer} from ISO

[role="_abstract"]
Update your disconnected {SmartProxyServer} to the next patch version by using ISO images.
You mount the ISO images on your disconnected {SmartProxyServer}, use them as the sources of the updated packages and container images, and redeploy {SmartProxyServer}.

The update process also updates the base operating system on your disconnected {SmartProxyServer} when a new minor version is available.

.Prerequisites
* You have downloaded and copied the binary DVD images of {RHEL} and {ProjectName} {ProjectVersion} to your disconnected {SmartProxyServer}.
For more information, see {InstallingServerDisconnectedDocURL}download-the-binary-dvd-images[Download the binary DVD images].

.Procedure
. Optional: On your disconnected {SmartProxyServer}, determine if the system is ready for update:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} health
----
+
Review the results and address any highlighted error conditions before performing the update.
. On your disconnected {SmartProxyServer}, mount the ISO images and configure the offline repositories.
For more information about configuring the offline repositories, see {InstallingServerDisconnectedDocURL}install-disconnected-{project-context}-server[Install disconnected {ProjectServer}].
. Update the base operating system:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {package-upgrade}
----
. Set up the local repositories and load the container images for {ProjectName} {ProjectVersion} from the mounted {Project} ISO image:
+
[options="nowrap"]
----
# /media/satellite/prepare_system
----
. Stop the existing {Project} services:
+
[options="nowrap" subs="+quotes,attributes"]
----
# systemctl stop foreman.target
----
. Redeploy the {SmartProxy} to perform the update:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} deploy-proxy
----
+
{Project} runs all required update tasks, including update tasks required by {Project} dependencies and your configured plugins.
As a result, this `{foremanctl} deploy-proxy` run might take longer than usual.

.Verification
* On your disconnected {SmartProxyServer}, verify that all {Project} services are running:
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foremanctl} health
----
