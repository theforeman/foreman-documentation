= Distributing SSH keys for remote execution

[role="_abstract"]
For {SmartProxies} in `ssh` mode, remote execution connections are authenticated using SSH.
By default, global registration deploys {SmartProxy} SSH public keys to hosts automatically.
You can disable this through the *Setup REX* option.

.Prerequisites
* The SSH service is enabled and running on the hosts.
* Any network or host-based firewalls are configured to enable access to port 22.
* If the hosts are running on Amazon Web Services, enable password authentication.
For more information, see https://aws.amazon.com/premiumsupport/knowledge-center/new-user-accounts-linux-instance[New User Accounts].

.Procedure
* If you register hosts by using global registration, leave *Setup REX* set to *Yes* (the default) to deploy SSH keys automatically.
For more information, see {ManagingHostsDocURL}registering-hosts-by-using-global-registration[Registering hosts by using global registration] in _{ManagingHostsDocTitle}_.
* If global registration did not deploy the SSH keys, or you use another provisioning method, use one of the following methods to distribute the public SSH key from {SmartProxy} to target hosts:
** xref:distributing-ssh-keys-for-remote-execution-manually[].
** xref:using-the-{project-context}-api-to-obtain-ssh-keys-for-remote-execution[].
** xref:configuring-a-{client-provisioning-template-type}-template-to-distribute-ssh-keys-during-provisioning[].
