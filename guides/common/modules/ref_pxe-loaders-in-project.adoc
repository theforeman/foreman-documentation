= PXE loaders in {Project}

[role="_abstract"]
A PXE loader defines the `filename` DHCPv4 option to use during provisioning.
{Project} deploys the required files to TFTP {SmartProxy}.

ifdef::satellite[]
[NOTE]
====
{Team} does not provide support for iPXE workflows.
====
endif::[]

.PXE loaders and DHCPv4 filenames
|===
| PXE loader option | `filename` value | Use for

| *None*
| No filename passed
| Non-PXE booting, for example HTTP booting with iPXE or image-based provisioning

| *PXELinux BIOS*
| `pxelinux.0`
| BIOS machines with PXE booting

| *PXELinux UEFI*
| `pxelinux.efi`
| UEFI machines with PXE booting

| *Grub2 BIOS*
| `grub2/grub__arch__.0`
| BIOS machines with PXE booting

| *Grub2 UEFI*
| `host-config/__mac__/grub2/boot.efi`
| UEFI machines with PXE boot using GRUB2

| *Grub2 UEFI SecureBoot*
| `host-config/__mac__/grub2/boot-sb.efi`
| SecureBoot-enabled UEFI machines with PXE booting

| *Grub2 UEFI HTTP*
| `http://__{smartproxy-example-com}__:8000/httpboot/host-config/__mac__/grub2/boot.efi`
| UEFI machines with HTTP booting

| *Grub2 UEFI HTTPS*
| `https://__{smartproxy-example-com}__:{smartproxy_port}/httpboot/host-config/__mac__/grub2/boot.efi`
| UEFI machines with HTTP booting over HTTPS

ifndef::satellite[]
| *Grub2 UEFI HTTPS SecureBoot*
| `https://__{smartproxy-example-com}__:{smartproxy_port}/httpboot/host-config/__mac__/grub2/boot-sb.efi`
| SecureBoot-enabled UEFI machines with HTTP booting over HTTPS
endif::[]

| *iPXE Embedded*
| {Project} iPXE URL
| Machines with iPXE embedded in their NIC firmware

| *iPXE UEFI HTTP*
| `http://__{smartproxy-example-com}__:8000/httpboot/ipxe-__arch__.efi`
| UEFI machines with HTTP boot using iPXE implementation

| *iPXE Chain BIOS*
| `undionly-ipxe.0`
| BIOS machines with PXE boot chainloading iPXE executable

| *iPXE Chain UEFI*
| `ipxe.efi`
| UEFI machines with PXE boot chainloading iPXE executable
|===

The Grub2 UEFI filenames shown here apply when the subnet's TFTP {SmartProxy} advertises `bootloader_universe`.
`__mac__` is the lowercase provisioning MAC address with colons replaced by hyphens.
Without the capability, {Project} uses the shared `grub2/grub__arch__.efi` or `grub2/shim__arch__.efi` filename, including in HTTP and HTTPS URLs.

ifndef::orcharhino,satellite[]
Other PXE loaders, such as *PXELinux UEFI* or *Grub2 ELF*, require additional configuration.
These workflows are not documented.
endif::[]
