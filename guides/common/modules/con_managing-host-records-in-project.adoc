= Managing host records in {Project}

[role="_abstract"]
Registration, provisioning, or discovery can create host records in {Project}.
When {Project} manages a host, you can configure its additional parameters.
You can remove a host record from {ProjectServer} after decommissioning a system or registering it elsewhere.
