= Managing host records in {Project}

[role="_abstract"]
Registration, provisioning, or Discovery can create host records in {Project}.
If a host is managed by {Project}, you can configure provisioning-related settings on the *Operating System* tab of the host details page.
You can remove a host record from {ProjectServer} after decommissioning a host or registering it elsewhere.
