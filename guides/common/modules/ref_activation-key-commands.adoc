= Activation key commands

[role="_abstract"]
You can create activation keys in {ProjectName} by using Hammer CLI commands.

[cols="3a,7a",options="header",]
|====
|Subcommand |Description and tasks
|`*activation-key*`
xref:use-common-hammer-commands[_organization-specific_]
|Create an activation key:
[subs="+quotes"]
----
hammer activation-key create \
--name _ak_name_ \
--content-view-environments _cvenv_label_
----
|====
