= Supported content types in {Project}

[role="_abstract"]
{ProjectName} supports a broad range of content types.

RPM packages::
RPM packages from synchronized repositories.
ifdef::satellite[]
This includes packages from Red{nbsp}Hat repositories and {customproduct} repositories.
endif::[]
ifndef::satellite[]
This includes packages from any upstream repository, such as CentOS, SUSE Linux Enterprise Server, or Red{nbsp}Hat.
endif::[]

Errata::
ifdef::orcharhino[]
Advisories for RPM-based and Deb content, including security fixes, bug fixes, and enhancements.
endif::[]
ifndef::orcharhino[]
Advisories for RPM-based content, including security fixes, bug fixes, and enhancements.
endif::[]
{Project} synchronizes errata from upstream repositories and makes them available for hosts through content views.

ifdef::katello,orcharhino[]
Deb packages::
Deb packages from upstream APT repositories, for example, for Debian or Ubuntu.
endif::[]

Kickstart trees::
Kickstart trees for provisioning {EL} hosts from synchronized repositories.
{Project} uses these trees as base content for network-based installations.

Container images::
Container images from container registries such as `registry.redhat.io` or other public or private registries.
You can synchronize container image repositories, manage them through content views, and publish them on {SmartProxyServers}.

Flatpak applications::
Desktop applications from Flatpak remotes.
You can connect to external Flatpak application indexes, mirror their content, and distribute it to hosts.

Ansible collections::
Ansible collections from any Ansible Galaxy endpoint.
ifdef::satellite[]
For example, `console.redhat.com` or other Ansible Galaxy servers.
endif::[]
You can synchronize and distribute Ansible collections to hosts.

ifdef::katello,orcharhino[]
OSTree content::
Bootable, immutable, versioned file system trees.
You can use OSTree to manage and update Linux-based operating systems on hosts and switch between versions.

Python packages::
Python packages from upstream sources such as PyPI or custom Python repositories.
You can synchronize, upload, and distribute Python packages through content views.

endif::[]
{customfiletypeFirstCap} content::
Arbitrary files of any type, such as ISO images, SSL certificates, Open Vulnerability and Assessment Language (OVAL) files, or source code.
You can upload files to a {customfiletype} repository or synchronize them from an upstream source.
