:_mod-docs-content-type: SNIPPET

[WARNING]
====
If a host is assigned to multiple content view environments, {Project} uses the first assigned content view environment to locate the image.
If the host's content view environment assignment order changes, a rebuild might use a different environment than originally intended.
To ensure {Project} uses the correct image, ensure that the desired boot image exists in the first content view environment assigned to the host.
For more information, see {ContentManagementDocURL}content-view-environment-ordering-and-priority[Content view environment ordering and priority] in _{ContentManagementDocTitle}_.
====
