= Install Flatpak applications on hosts

[role="_abstract"]
After you synchronize Flatpak repositories in {Project}, you can install Flatpak applications on hosts from {ProjectServer} or {SmartProxyServer}.
On each host, add a Flatpak remote, authenticate to the container registry, and install the applications you need.
