= Change a lifecycle environment by using {Project} API

[role="_abstract"]
You can modify lifecycle environment attributes such as name or description using a PUT request.

.Procedure
* Change your lifecycle environment:
+
[options="nowrap", subs="+quotes,attributes"]
----
$ curl \
--data '{"description":"Quality Acceptance Testing"}' \
--header "Accept: application/json" \
--header "Content-Type: application/json" \
--request PUT \
--user _My_User_Name_:__My_Password__ \
https://_{foreman-example-com}_/katello/api/environments/_My_Lifecycle_Environment_ID_/ \
| python3 -m json.tool
----
+
