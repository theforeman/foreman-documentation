= Import an ISO image by using Hammer CLI

[role="_abstract"]
You can manually import an ISO image to {ProjectServer} by using Hammer CLI.
You must use the Hammer CLI to upload files larger than 15 MB to a repository.

.Procedure
. Create the {customproduct}:
+
[options="nowrap" subs="+quotes"]
----
$ hammer product create \
--description "_My_Product_" \
--name "_My_Product_" \
--organization "_My_Organization_" \
--sync-plan "_My_Sync_Plan_"
----
. Create the repository:
+
[options="nowrap" subs="+quotes"]
----
$ hammer repository create \
--content-type "file" \
--name "_My_Repository_" \
--organization "_My_Organization_" \
--product "_My_Product_"
----
. Upload the ISO file to the repository:
+
[options="nowrap" subs="+quotes"]
----
$ hammer repository upload-content \
--id _My_Repository_ID_ \
--organization "_My_Organization_" \
--path ~/_My_ISO_Image.iso_
----
