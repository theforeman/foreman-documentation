= Import an Ansible Execution Environment by using {ProjectWebUI}

[role="_abstract"]
You can import an Ansible Execution Environment in {Project} by using {ProjectWebUI}.
This helps you reuse existing Ansible Execution Environments or use Ansible Director in a disconnected environment.

.Prerequisites
* Your {Project} account has a role that grants the `create_ansible_execution_environments`, `edit_ansible_execution_environments`, `view_ansible_content`, `view_ansible_execution_environments`, and `view_organizations` permissions.
* If your Ansible Execution Environment is not pullable from a container registry without authentication, upload the container image as Docker type content to {Project}.

.Procedure
. In the {ProjectWebUI}, navigate to *Ansible* > *Execution Environments*.
. Click *Import Execution Environment*.
. In the *Name* field, enter the name of your Ansible Execution Environment.
. In the *Container Image URL* field, enter the URL of your container image.
You can reference any container image from an OCI-compatible container registry or any container image that you have synchronized to {Project}.
Afterwards, navigate to *Content* > *Container Images* and from the actions menu, click *View pullable paths* to get the URL.
+
{Team} recommends to use a fully qualified container image name, for example, `{ansible-director-container-image-name}`.
. Click the *Save* icon to import your Ansible Execution Environment.

.Verification
. In the {ProjectWebUI}, navigate to *Ansible* > *Execution Environments*.
. Verify that {Project} has sucessfully imported your Ansible Execution Environment.
