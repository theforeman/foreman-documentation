* Inspect the key usage of the deployed certificate:
+
[options="nowrap", subs="+quotes,attributes"]
----
$ openssl s_client -connect {foreman-example-com}:443 </dev/null 2>/dev/null \
| openssl x509 -noout -text | grep -A1 "X509v3 Key Usage"
----
+
For RSA, the key usage includes `Digital Signature` and `Key Encipherment`.
For ECC and ML-DSA, the key usage includes `Digital Signature` only.
