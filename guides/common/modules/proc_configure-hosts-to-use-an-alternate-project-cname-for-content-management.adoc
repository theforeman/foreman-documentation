= Configure hosts to use an alternate {Project} CNAME for content management

[role="_abstract"]
If {Project} is configured with an alternate CNAME, you can configure hosts to use that CNAME for content management.
Point hosts to the alternate {Project} CNAME before you register them to {Project}.

Perform these steps on the hosts you want to configure.

.Procedure
* Edit the `/etc/rhsm/rhsm.conf` file to update the `hostname` and `baseurl` settings to point to the alternate host name, for example:
+
[source, none, options="nowrap" subs="+quotes,attributes"]
----
[server]
# Server hostname:
hostname = _My-Alternate-FQDN.example.com_

_content omitted_

[rhsm]
# Content base URL:
baseurl=https://_My-Alternate-FQDN.example.com_/pulp/content/
----

.Next steps
* Register the host by using `subscription-manager`.
