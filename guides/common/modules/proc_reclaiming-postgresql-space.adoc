= Reclaiming PostgreSQL space

[role="_abstract"]
If the PostgreSQL database is using a large amount of disk space, you can reclaim space by vacuuming the database.
By reclaiming PostgreSQL space, you can reduce the amount of disk space used by {Project}.

.Procedure

. Stop all services, except for the `postgresql` service:
ifndef::containerized[]
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foreman-maintain} service stop --exclude postgresql
----
endif::[]
ifdef::containerized[]
+
[options="nowrap" subs="+quotes,attributes"]
----
# systemctl stop foreman.target && systemctl start postgresql.service
----
endif::[]
. Switch to the `postgres` user and reclaim space on the database:
ifndef::containerized[]
+
[options="nowrap"]
----
# su - postgres -c 'vacuumdb --full --all'
----
endif::[]
ifdef::containerized[]
+
[options="nowrap"]
----
# podman exec postgresql vacuumdb -U postgres --full --all
----
endif::[]
. Start the other services when the vacuum completes:
ifndef::containerized[]
+
[options="nowrap" subs="+quotes,attributes"]
----
# {foreman-maintain} service start
----
endif::[]
ifdef::containerized[]
+
[options="nowrap" subs="+quotes,attributes"]
----
# systemctl start foreman.target
----
endif::[]
