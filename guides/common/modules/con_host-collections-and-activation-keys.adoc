= Host collections and activation keys

[role="_abstract"]
You can use host collections in combination with activation keys to standardize installing software and applying errata on your hosts.

Assigning newly provisioned or registered hosts to a host collection::
You can assign host collections to an activation key to automatically assign hosts that register to {Project} using this activation key to your host collection.

Assigning existing hosts that use a specific activation key to a host collection::
You can filter your hosts on the *All Hosts* page by activation key and then assign them to your host collection by using a bulk action.
