:_mod-docs-content-type: SNIPPET

You can export the following content types in the syncable format from {ProjectServer}:

* {customfiletypeFirstCap} content
* Kickstart repositories
* Yum content

You cannot export
ifdef::satellite[]
Ansible collections, Docker content, or Python content
endif::[]
ifndef::satellite[]
Ansible collections, Deb content, Docker content, or Python content
endif::[]
in the syncable format.
