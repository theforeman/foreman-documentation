= Run Ansible roles on a host group

[role="_abstract"]
When a host group has one or more Ansible roles assigned to it, {Project} can run the roles on all hosts in the host group at once to apply and enforce the configuration state that the roles define.

.Prerequisites
* The public SSH key from {SmartProxy} is available on the hosts in the host group.
For more information, see {ManagingHostsDocURL}distribute-ssh-keys-for-remote-execution[Distribute SSH keys for remote execution].

.Procedure
. In the {ProjectWebUI}, navigate to *Configure* > *Host Groups*.
. From the list in the *Actions* column for the host group, select *Run all Ansible roles*.
. You can view the status of your Ansible job on the *Run Ansible roles* page.
Click *Rerun* to rerun a job.
