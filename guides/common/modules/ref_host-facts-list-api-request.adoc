= Host facts list API request

[role="_abstract"]
You can retrieve system facts such as hardware details, BIOS version, and installed software for a specific host.

Example API request::
+
[options="nowrap", subs="+quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--header "Content-Type: application/json" \
--request GET \
--user _My_User_Name_:__My_Password__ \
https://_{foreman-example-com}_/api/v2/hosts/_{server-example-com}_/facts \
| python3 -m json.tool
----

Example API response::
+
[source, json, options="nowrap", subs="+quotes,attributes"]
----
{
    ...
    "results": {
        "_{server-example-com}_": {
            "augeasversion": "1.0.0",
            "bios_release_date": "01/01/2007",
            "bios_version": "0.5.1",
            "blockdevice_sr0_size": "1073741312",
            "facterversion": "1.7.6",
            ...
}
----
