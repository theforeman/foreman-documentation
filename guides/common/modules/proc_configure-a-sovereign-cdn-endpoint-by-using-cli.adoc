= Configure a sovereign CDN endpoint by using Hammer CLI

[role="_abstract"]
Configure your {ProjectServer} to synchronize Red{nbsp}Hat content from a sovereign CDN endpoint instead of the default `cdn.redhat.com` endpoint.
Use this to ensure that content synchronization uses an endpoint in your preferred jurisdiction.

.Prerequisites
* You have uploaded a manifest to your organization.

.Procedure
. Connect to your {ProjectServer} using SSH.
. Set CDN configuration to a sovereign CDN endpoint:
+
[options="nowrap" subs="+quotes,attributes"]
----
$ hammer organization configure-cdn \
--name="_My_Organization_" \
--type=custom_cdn \
--url https://cdn-eu.redhat.com
----
+
Replace `cdn-eu.redhat.com` with `cdn-us.redhat.com` if you are in the United States.
