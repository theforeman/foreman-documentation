= Manually tuning Puma workers and thread count

[role="_abstract"]
Manual tuning allows you to override auto-tuning when your specific workload or hardware configuration requires different worker and thread counts than the defaults provide.

For example, the following configuration uses two workers and five threads:

[options="nowrap", subs="+attributes"]
----
# {foreman-installer} \
--foreman-foreman-service-puma-workers 2 \
--foreman-foreman-service-puma-threads-max 5
----
