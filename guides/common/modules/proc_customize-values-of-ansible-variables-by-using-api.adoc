= Customize values of Ansible variables by using {Project} API

[role="_abstract"]
You can set custom values of Ansible variables in {Project} by using {Project} API.

.Prerequisites
* Your {Project} account has a role that grants the `create_ansible_director_variable_overrides`, `destroy_ansible_director_variable_overrides`, `destroy_ansible_variables`, `edit_ansible_director_variable_overrides`, `edit_ansible_director_variables`, `view_ansible_content`, `view_ansible_director_variable_overrides`, `view_ansible_director_variables`, and `view_organizations` permissions.
* Your {Project} contains imported Ansible content.

.Procedure
. Optional: Get a list of Ansible content IDs:
+
[options="nowrap", subs="verbatim,quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--user "_My_User_Name_:__My_Password__" \
https://{foreman-example-com}/api/v2/ansible_director/ansible_content/ \
| jq ".results [] .id"
----
+
Note down the ID of your Ansible content in {Project}.
. Optional: Get a list of Ansible roles in your Ansible content:
+
[options="nowrap", subs="verbatim,quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--user "_My_User_Name_:__My_Password__" \
https://{foreman-example-com}/api/v2/ansible_director/ansible_content/_My_Ansible_Content_ID_/ \
| jq ".roles [] .name"
----
. Optional: Get a list of variables in your Ansible roles:
+
[options="nowrap", subs="verbatim,quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--user "_My_User_Name_:__My_Password__" \
https://{foreman-example-com}/api/v2/ansible_director/ansible_content/_My_Ansible_Content_ID_/ \
| jq ".roles []" | jq 'select(.name == "_My_Ansible_Role_Name_")' | jq ".variables []"
----
+
Note down the ID of the Ansible variable that you want to customize.
. Create a JSON file, for example, `data.json` to define your custom value:
+
[source, json, options="nowrap", subs="verbatim,quotes,attributes"]
----
{
  "ansible_variable_binding": {
    "data_type": "_My_Ansible_Variable_Type_",
    "raw_value": "---\n_My_Value_\n",
    "target": "_My_Target_Type_",
    "target_id": _My_Target_ID_,
    "assignable_role_name": "_My_Ansible_Role_Name_",
    "assignable_name": "_My_Ansible_Collection_Name_",
    "assignable_namespace": "_My_Ansible_Namespace_",
    "assignable_type": "ForemanAnsibleDirector::AnsibleCollectionRole",
    "variable_name": "_My_Ansible_Variable_Name_"
  }
}
----
+
Set the target type to either `hostgroup` to match host groups or `host` to match hosts.
. Set a custom value for an Ansible variable:
+
[options="nowrap", subs="verbatim,quotes,attributes"]
----
$ curl \
--data @data.json \
--header "Accept: application/json" \
--header "Content-Type: application/json" \
--request POST \
--user "_My_User_Name_:__My_Password__" \
https://{foreman-example-com}/api/v2/ansible_director/ansible_variables/bindings/ \
| jq
----

.Verification
* Query the {Project} API to verify that {Project} set the Ansible variable binding successfully:
+
[options="nowrap", subs="verbatim,quotes,attributes"]
----
$ curl \
--header "Accept: application/json" \
--user "_My_User_Name_:__My_Password__" \
https://{foreman-example-com}/api/v2/ansible_director/ansible_variables/_My_Target_Type_/_My_Host_ID_/single/ \
| jq
----
+
Set the target type to either `hostgroup` for a host group or `host` for a host.
