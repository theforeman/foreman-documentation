= Accessing Grafana remotely

[role="_abstract"]
By default, Grafana runs on `+http://localhost:3000+` on the {ProjectServer} and is only accessible locally.
To access Grafana from a remote workstation, you can create an SSH tunnel that forwards your local port 3000 to the {ProjectServer} port 3000.
Choose the procedure that matches your workstation's operating system and tools.
