= Built-in {Project} API documentation

[role="_abstract"]
You can use the built-in API reference on your {ProjectServer} to view information about API endpoints supported for {Project} API integrations.

View the full API reference on your {ProjectServer} at the following URL:

[source, none, options="nowrap", subs="+quotes,attributes"]
----
https://_{foreman-example-com}_/apidoc/
----

Replace _{foreman-example-com}_ with the FQDN of your {ProjectServer}.
