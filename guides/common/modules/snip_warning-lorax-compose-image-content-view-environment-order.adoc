[WARNING]
====
If a host is assigned to multiple content view environments, {Project} uses the first assigned content view environment to locate the image.
If you change the order of the content view environments assigned to the host, rebuilding the host might use a different environment from the one that you intended.
To ensure {Project} uses the correct image, ensure that the desired boot image exists in the first content view environment assigned to the host.
For more information, see {ContentManagementDocURL}content-view-environment-ordering-and-priority[Content view environment ordering and priority].
====
