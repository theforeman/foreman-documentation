= Manage host records in {Project}
[role="_abstract"]
Registration, provisioning, or Discovery can create host records in {Project}.
If a host is managed by {Project}, you can configure provisioning-related settings on the *Operating System* tab when editing the host.
You can remove a host record from {ProjectServer} after decommissioning a host or registering it elsewhere.
By default, unregistering a host by using `subscription-manager` does not remove its host record.
To remove the record automatically, enable the *Delete Host upon unregister* setting.
When enabled, linked resources such as virtual machines and DNS records might also be deleted.
For more information, see {AdministeringDocURL}content-management-settings[Content management settings in _{AdministeringDocTitle}_].
