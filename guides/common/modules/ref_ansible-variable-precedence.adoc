= Ansible variable precedence

[role="_abstract"]
You can define values of Ansible variables at different levels in {Project}.
The Ansible variable precedence describes the order of inheritance.

Ansible content::
By convention, Ansible content that adheres to Ansible good practices defines default values for Ansible roles and playbooks.
{Project} uses those values as default values.

Global overrides::
Global overrides are useful to set default values for your {Project} environment.
They override the default values of imported Ansible content.

Bindings::
Bindings in {Project} define the type and value for Ansible variables.
They can override Ansible variables for host groups or hosts.
They override the default values of global overrides.
