= Setting the OpenVox agent run interval on a host

Set the interval when the OpenVox agent runs and sends reports to {Project}.

.Procedure
. Connect to your host using SSH.
. Add the OpenVox agent run interval to `/etc/puppetlabs/puppet/puppet.conf`, for example `runinterval = 1h`.
