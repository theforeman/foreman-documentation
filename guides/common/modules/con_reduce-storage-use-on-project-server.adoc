[id="reduce-storage-use-on-{project-context}-server"]
= Reduce storage use on {ProjectServer}

[role="_abstract"]
{ProjectServer} can accumulate a large amount of data over time, which can use a significant amount of disk space.
ifndef::containerized[]
You can clean up database records or reclaim disk space to reduce storage use.
endif::[]
ifdef::containerized[]
You can clean up task records to reduce storage use.
endif::[]
