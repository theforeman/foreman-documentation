// cross-document links. Emptied in the Maps build (:map:) so the aggregated navigation
// does not show a dangling "in _Book Title_" after links that resolve internally.
// The leading space lives inside the value, so when emptied nothing (not even a space)
// is left behind. Wrapped in pass:a,q[] because attribute references are substituted
// after inline formatting (quotes): without the passthrough the title's _..._ emphasis
// would render as literal underscores. pass:a,q re-applies attributes then quotes to
// the value, so the title resolves and renders italic in every non-map build.
