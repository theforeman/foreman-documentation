// Companion "always external" variants of the cross-guide *DocURL attributes.
//
// A *DocURL attribute is used two ways:
//   * {FooDocURL}anchor[text] - link to a SECTION of another guide
//   * {FooDocURL}[text]       - link to another guide AS A WHOLE
//
// The Maps guide overrides every *DocURL to `xref:` so SECTION links resolve
// to the reused module inside the single-page map (see
// attributes-map-overrides.adoc). That rewrite is wrong for WHOLE-GUIDE links:
// `xref:[text]` has no target and renders as broken literal text, because a
// whole guide has no single equivalent anchor inside the map.
//
// So whole-guide links use these *DocURLExternal variants instead. They are
// snapshotted from the external *DocURL value here - after the build-specific
// attributes are loaded but before the map override runs - so they keep
// pointing at the published standalone guide in every build, including the map.
//
// Only attributes actually used as whole-guide links are listed. If you add a
// {FooDocURL}[text] link, add the matching :FooDocURLExternal: here.
